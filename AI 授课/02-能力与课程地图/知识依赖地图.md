# 知识依赖地图

```text
计算机与命令行基础
        ↓
Python → 文件/JSON → HTTP/API → Git
        ↓
大模型基础 → Prompt → 模型 API
        ↓
结构化输出 → 多轮会话 → 上下文管理
        ↓
Embedding → 文档切分 → 检索 → RAG → RAG评测
        ↓
Function Calling → MCP → 权限与异常处理
        ↓
状态管理 → 工作流 → 记忆 → Agent
        ↓
测试集 → Rubric → 可观测性 → 安全与成本
        ↓
前后端 → 数据库 → 部署 → 毕业项目
```

## 维护规则

- 新增知识点前必须标注前置知识；
- 删除知识点前必须检查后续依赖；
- 高频失败点应增加补课节点；
- 容易变化的框架知识和稳定原理分开维护。
