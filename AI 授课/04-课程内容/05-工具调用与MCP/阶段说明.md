# 工具调用与 MCP

## 阶段定位

让模型不只生成文字，而能在程序控制下读取数据和执行动作。核心不是“工具越多越好”，而是契约清晰、权限最小、失败可控、行为可审计。

## 可验收能力

- 设计清晰、可校验的工具定义
- 实现模型选择工具、程序执行和结果回传闭环
- 控制权限、确认、超时、重试和副作用
- 理解 MCP 的角色并接入受控资源或工具

## 前置知识

- 能实现结构化输出和异常处理
- 理解 API 与客户端/服务端基本关系
