# Python 与 API 基础

## 阶段定位

只学习开发 AI 应用所需的最小编程闭环。每个语法点都进入命令行 AI 助手，不做脱离项目的大量算法练习。

- 使用变量、函数、条件、循环和异常处理组织小程序

- 解释 HTTP 请求、响应、状态码与 API 鉴权
- 使用 Git 保存可回退的代码版本

- 完成阶段一 Prompt 工作台
- 具备基本文件与目录操作能力
