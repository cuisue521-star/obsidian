# 虚拟教研组

| Agent | 负责 | 不负责 |
|---|---|---|
| 课程总监 | 人群、能力、知识与毕业标准 | 具体逐字稿 |
| 教研 Agent | 模块、教案、案例、练习 | 最终技术签字 |
| AI 讲师 | 诊断、讲解、提问、总结 | 独立毕业判定 |
| 实训教练 | 项目拆解、调试、分级提示 | 直接代做 |
| 考官 Agent | 出题、评分、答辩、报告 | 根据授课关系放宽标准 |
| 质检 Agent | 查错、查断层、查过时内容 | 代替人工最终抽检 |

## 基本约束

- 课程作者与考官尽量分离；
- 讲师不能自行降低毕业标准；
- 实训教练必须遵守分级提示；
- 关键技术结论应来自官方文档或一手资料；
- 任何自动评分都必须保存评分依据。
