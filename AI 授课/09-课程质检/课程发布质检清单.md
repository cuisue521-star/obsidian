# 课程发布质检清单

## 内容
- [ ] 学习目标具体且可测量
- [ ] 与能力模型和项目目标一致
- [ ] 前置知识完整，无明显断层
- [ ] 核心事实有可靠来源
- [ ] 易变技术标注版本和验证日期

## 代码与实训
- [ ] 示例代码在指定环境运行通过
- [ ] 依赖版本明确
- [ ] 异常情况有处理说明
- [ ] 作业与课堂内容匹配
- [ ] 自动测试能够识别关键错误

## 教学设计
- [ ] 有前置检查、讲解、示例和练习
- [ ] 练习不是简单复制作业
- [ ] 有常见错误与补救路径
- [ ] 提示不会过早暴露完整答案
- [ ] 难度和时长适合目标学员

## 测评
- [ ] 标准答案或参考答案合理
- [ ] Rubric 明确、可复核
- [ ] 考官与作者角色分离
- [ ] 通过标准与毕业能力一致

## 发布
- [ ] 技术审核通过
- [ ] 教学审核通过
- [ ] 质检审核通过
- [ ] 人工抽检通过
- [ ] 版本记录已更新
