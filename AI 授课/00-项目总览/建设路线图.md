# 建设路线图

## Phase 1：课程母版

- [ ] 确定目标学员
- [ ] 定义毕业能力
- [ ] 建立能力模型
- [ ] 建立知识依赖地图
- [ ] 建立项目路线图
- [ ] 完成课程研发、课时、项目和测评模板

## Phase 2：样板模块

- [ ] 选择 5～10 节课的完整模块
- [ ] 编写讲义、示例、练习和作业
- [ ] 制作可运行代码及自动测试
- [ ] 配置 AI 讲师与实训教练 Prompt
- [ ] 建立模块考试与项目验收标准

建议样板：**大模型 API 与结构化输出**。

## Phase 3：个人试学

- [ ] 按真实学员身份完成课程
- [ ] 记录卡点、错误和放弃风险
- [ ] 检验 AI 是否过早给答案
- [ ] 检验评分是否稳定
- [ ] 修订课程与授课规则

## Phase 4：小规模内测

- [ ] 零基础学员 1 人
- [ ] 产品／运营背景学员 1 人
- [ ] 开发背景学员 1 人
- [ ] 汇总完成率、掌握率和项目通过率

## Phase 5：产品化

- [ ] 用户与课程管理
- [ ] 学习进度与长期记忆
- [ ] 在线作业／代码提交
- [ ] 自动测评与学习报告
- [ ] 课程版本与回归验证
