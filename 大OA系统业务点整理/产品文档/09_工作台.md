# 09\_工作台

***

## 一、文档概述

### 1.1 产品定位

工作台是「项目审批系统」的核心操作入口，聚合流程发起、待处理流程管理、最近项目快捷访问、日程管理等功能，是用户开展项目审批操作的"一站式操作中心"。

### 1.2 版本信息

- 版本：V1.0
- 发布时间：2026.01.29
- 更新时间：2026.01.30

### 1.3 目标用户

| 用户角色  | 核心诉求             | 操作场景                 |
| ----- | ---------------- | -------------------- |
| 审批经办人 | 快速定位并处理待审批流程     | 每日上班后进入工作台处理待办流程     |
| 流程发起人 | 便捷发起常用项目流程       | 发起项目立项、还款流程时快速找到入口   |
| 项目管理员 | 统筹查看项目动态、日程及关联流程 | 日常巡检项目进度时查看最近项目与待办流程 |

## 二、页面结构

### 2.1 整体布局

工作台页面分为**左侧功能侧边栏**和**右侧主内容区**两部分：

- **页面宽度**：适配1920×1080、1366×768分辨率
- **左侧区域**：固定宽度约300px，包含顶部导航、流程发起、最近项目、日程日历
- **右侧区域**：自适应宽度，包含流程筛选和流程列表

### 2.2 顶部导航栏

页面顶部包含全局导航元素：

**左侧**：

- 系统Logo + 系统名称"项目审批系统"

**中间**：主导航栏，包含4个导航项

- 工作台（当前选中，高亮蓝色）
- 流程管理
- 项目管理
- 征信管理

**右侧**：

- 消息通知图标（铃铛），有红点表示有未读消息
- 设置图标（齿轮）
- 用户头像图标
- 企业标识："中诺数科"（带下拉箭头）下拉可切换当前登录主体

## 三、左侧功能区域

### 3.1 流程发起模块

#### 3.1.1 页面元素

位于左侧顶部区域，包含以下元素：

**"+ 发起流程"按钮**：

- 样式：蓝色背景按钮，宽度100%
- 位置：左侧功能区顶部
- 图标："+"号图标 + 文字"发起流程"
- 交互效果：鼠标悬停时背景色加深

**常用流程区**：

- 标题："常用流程"
- 流程标签列表：3个常用流程快捷标签
  - 企业利润及利润分配表(首次获取)
  - 项目立项
  - 约定还款(逾期还款)
- 样式：灰色胶囊状标签
- 交互效果：鼠标悬停时背景变浅蓝色

#### 3.1.2 功能说明

**发起流程按钮功能**：

- 点击"+ 发起流程"按钮后，弹出全量流程选择弹窗
- 弹窗包含所有可发起的流程分类和具体流程项
- 用户可在弹窗中搜索或浏览流程列表
- 选择流程后，弹窗关闭，跳转至对应流程的发起表单页

**常用流程标签功能**：

- 直接点击任意常用流程标签
- 无需弹窗选择，直接跳转至该流程的发起表单页
- 展示最近发起过的三个，若无展示空。判断标准为成功发起后视为发起过
- 排序为发起时间倒序。最新的在最左边

### 3.2 最近打开的项目模块

#### 3.2.1 页面元素

位于流程发起模块下方，包含：

**标题区**：

- 文字："最近打开的项目："（带冒号）

**项目标签列表**：

- 展示数量：最多6个项目
- 每个项目显示为胶囊状标签
- 样式：灰色背景
- 交互效果：鼠标悬停时背景变浅蓝色

#### 3.2.2 功能说明

**项目快捷访问**：

- 点击任意项目标签
- 跳转至该项目的详情页面
- 按最近操作时间倒序排列（最近操作的排在最前面）。点击进入项目详情，视为最近操作

**空状态处理**：

- 当用户无最近项目记录时
- 显示："暂无最近项目" + 空状态图标

### 3.3 日程日历模块

#### 3.3.1 页面元素

位于左侧底部，包含：

**年月选择区**：

- 样式：两个下拉框并排显示
  - 左侧年份下拉框：显示当前年份（如"2025"），可切换其他年份
  - 右侧月份下拉框：显示当前月份（如"12月"），可切换其他月份
- 下拉框样式：白色背景，灰色边框，点击展开选择面板

**日历主体**：

- 布局：7列（日-六）× 5-6行网格布局
- 星期标题行：日、一、二、三、四、五、六（灰色文字，居中）
- 日期格子：每个格子显示日期数字（黑色文字，居中）
- 格子高度：约40-50px，保持正方形或接近正方形
- 格子边框：浅灰色细边框分隔
- 当前日期标记：今天的日期显示蓝色边框或背景色强调

**日程标记**：

- 标记位置：日期格子内部，日期数字下方
- 标记内容：
  - 自己做的笔记，展示前四个字，剩余用...表示。不展示空格。
  - 系统信息，包括：
    - 还款计划里，今天应该还款的信息。样式同资金概览，金额展示不开用...展示
    - 付款计划里，今天应该付款的信息。样式同资金概览，金额展示不开用...展示
  - 总结：若没有笔记，最多展示两行，若有笔记，可能多个。
- 标记形式：
  - 文字标记：如"项目会议 审批付款 +1"、"培训会议 月度总结 +999"
    - 文字较小（约10-12px），黑色或灰色
    - 超长文本省略显示（如"培训会议..."）
  - 数量标记：如"+1"、"+999"
    - 显示在日程标记末尾
    - 标记还有多少没展示出来！！！
- 标记颜色：
  - 普通日程：黑色或灰色文字
  - 蓝色高亮日期：特定日期显示蓝色标记（如12月20日、27日，日期数字蓝色或背景蓝色）-不在本次需求内
- 数据权限：
  - 自己的备忘录，仅自己可见
  - 备忘录跨主体展示，应收应付按主体展示！
  - 应收应付信息有数据权限，不得查看没权限的还款和付款计划。

**当前选中日期**：

- 选中日期：12月18日
- 样式：蓝色背景，白色文字

**月份边界处理**：

- 日历显示当前月份完整日期
- 下个月/上个月的日期：以浅灰色显示（如显示2026年1月1-5日的日期，浅灰色，表示属于下个月）

#### 3.3.2 功能说明

**年月切换功能**：

- 点击年份下拉框，选择年份后，日历刷新对应年份
- 点击月份下拉框，选择月份后，日历刷新对应月份
- 默认显示当前年月

**日程查看功能**：

- 日历上的日程标记来自两部分：
  1. **系统待处理日程**：流程中关联的截止日期、会议日程等-不在本次需求内
  2. **个人备忘日程**：用户在备忘录中添加的日程
- 点击日程标记，跳转至对应的流程详情页或日程详情页

**日期选择功能**：

- 点击任意日期格子
- 该日期变为选中状态（蓝色背景）
- 弹出该日期的备忘录抽屉
- 抽屉标题："备忘录 YYYY-MM-DD (X)"，X为该日期的备忘录数量

#### 3.3.3 备忘录管理

**备忘录抽屉界面**：

- 触发方式：点击日历中任意日期（如点击12月18日）
- 位置：从右侧滑出，覆盖部分日历区域
- 宽度：约400px（或与日历区域宽度相同）
- 高度：自适应内容，最大不超过页面高度
- 遮罩层：半透明黑色遮罩（rgba(0,0,0,0.45)），覆盖整个页面
- 标题栏：
  - 标题文字："备忘录 2025-12-11 (0)"（日期根据选中的日期动态变化）
    - 格式："备忘录 YYYY-MM-DD (X)"，X为该日期的备忘录数量
  - 标题样式：16px，加粗，黑色
  - 右上角关闭按钮："×"图标，灰色，点击关闭抽屉

**输入区域**：

- 字数统计：
  - 格式："已输入字数/最大字数"，如"25/200"
  - 实时更新：每输入一个字，字数统计立即更新
- 超长提示：
  - 超过200字时，字数统计变红色（#f5222d）
  - 输入框边框变红色

**按钮区域**（输入框下方）：

- 布局：按钮横向排列
- "编辑"按钮：
  - 选中备忘录后，点击可进入编辑模式。
- "+ 添加备忘"按钮：
  - 功能：添加新备忘，把当前录入文字添加到系统里，添加后下方增加一条。根据添加时间倒序。系统添加的按照添加时间倒序。优先展示系统信息，

**空状态处理**：

- 当该日期无备忘录时
- 列表区域显示："暂无备忘录" + 空状态插画
- 空状态文字居中，灰色（#999）

**删除备忘**：

1. 点击备忘录右侧的删除图标（垃圾桶）
2. 弹出确认删除弹窗："确认删除此备忘？"
3. 点击"确认"按钮，备忘录删除
4. 点击"取消"按钮，弹窗关闭，备忘录保持不变

**关闭抽屉**：

- 点击抽屉右上角的"×"按钮
- 点击半透明遮罩层
- 抽屉向右滑出关闭

## 四、右侧主内容区

### 4.1 流程状态与企业筛选栏

#### 4.1.1 页面元素

**流程状态标签栏**：

- 位置：右侧内容区顶部
- 布局：三个标签卡片横向排列，等宽分布
- 标签内容：
  1. "待处理(28)"
  2. "待推送(8)"
  3. "已发起(5) 进行中"
- 数字说明：括号内数字表示该状态的流程总数
- 样式规范：
  - **当前选中标签**：
    - 边框：无边框
    - 底部：无下划线
  - **未选中标签**：
    - 边框：无边框
    - 底部：无下划线
    - 鼠标悬停时：背景色变为浅蓝色
- "已发起"标签特殊说明：
  - 标签末尾显示"进行中"标识
  - 表示已发起流程的状态为进行中（未通过/未办结/未拒绝/未作废）
  - "进行中"样式：与标签文字同色，同一行显示
- 交互效果：
  - 点击标签后，标签状态切换（选中/未选中）
  - 下方流程列表刷新为对应标签的内容
  - 列表刷新时显示骨架屏或Loading动画

**企业筛选栏**：

- 位置：状态标签栏下方，与状态标签栏左对齐
- 布局：横向滚动的企业标签列表
- 标签样式：胶囊形状，横向排列
- 当前企业标签：
  - 内容："北京中诺链捷数字科技有限公司(19)"
    - 企业名称：完整显示（或超长时省略显示）
    - 括号内数字：该企业的待处理流程数量
- 其他企业标签：
  - 示例标签：
    1. "中诺商业保理(9)..."
    2. "文案文案文案(0)..."
    3. 其他企业标签（如"文案文案文案(0)..."）
- 企业名称省略规则：
  - 超长企业名称：显示前六个字符 + "..."（如"文案文案文案..."）
  - 括号内数字始终显示
- 右侧箭头图标：
  - 位置：企业标签列表最右侧
  - 样式：灰色箭头图标（>），表示可横向滑动查看更多企业
  - 交互效果：点击，企业标签列表横向滚动
- 数字为0的处理：
  - 企业标签括号内数字为0时，显示"0"
  - 仍可点击切换到该企业
  - 切换后流程列表显示空状态（"暂无待处理流程"）
- 排序规则
  - 默认按照系统数据库排序
  - 若存在待办，按数值大小从大到小排列
  - 若数字相同，使用默认排序

#### 4.1.2 功能说明

**流程状态切换**：

- 标签切换时，下方流程列表刷新，获取最新数据
- DOD：标签后是0，此时点击这个企业，获取最新信息，若此时有一个新待办，页面刷新，能看到这个待办，企业标签后展示为1

**企业筛选**：

- 点击任意企业标签
- 流程列表刷新为该企业的流程
- 企业标签栏支持横向滑动，查看更多企业
- 企业标签后的数字表示该企业的待处理流程数量

**待推送标签的特殊规则**：

- "待推送"标签仅对特定企业可见（如"中诺商业保理(深圳)有限公司"具备牌照）
- 若当前用户所属企业不具备牌照，则不显示"待推送"标签
- 此规则需后台配置控制，兼容未来其他企业拥有该牌照的功能

### 4.2 流程搜索与筛选区域

#### 4.2.1 页面元素

**五个搜索/筛选条件**：

1. **项目名称**：

   模糊匹配（如输入"项目"，可匹配"XX项目"）

   输入非法字符（非字母和数字）时，自动过滤
4. **发起人**：

   支持发起人姓名的模糊匹配

   匹配列表的所有发起人
5. **流程类型下拉框**：
6. **字段检索输入框**：

   功能说明：支持审批流所有字段的检索（如金额、时间、审批人等）

### 4.3 待处理流程列表

#### 4.3.1 页面元素

位于搜索筛选区域下方，展示当前需审批的流程。

时效信息：

- **发起时间**：
  - 内容："2022-02-02 09:00:00"
  - 说明：流程发起的完整时间（年-月-日 时:分:秒）
  - 格式：YYYY-MM-DD HH:mm:ss
- **总耗时**：
  - 内容："1天2小时15分钟"
  - 说明：流程从发起到当前的总时间
  - 格式：X天X小时X分钟（不需根据实际时间动态变化，以页面刷新时间为准）
- **当前等待**：
  - 内容："15分钟"或"1天10分钟"
  - 说明：当前审批节点的等待时间
  - 格式：X天X小时X分钟
- **时效高亮规则**：
  - 当前等待时间超过1天：显示为红色，字体加粗
  - 当前等待时间未超过1天：显示为灰色
  - 示例：
    - "15分钟"：灰色（正常）
    - "1天10分钟"：红色（超时，需优先处理）

**右下角 - 操作按钮区域**：

- **"处理"按钮**：
  - 功能说明：点击后进入流程审批页面，进行审批操作

**列表排序规则**：

- 默认排序：按发起时间倒序

**"催办"按钮**：

- 位置：卡片右下角
- 显示条件：流程已流转至下一节点，当前等待审批人处理
- 点击发送催办通知给当前审批人
- 功能说明：点击后向当前审批人发送催办提醒，加快审批进度。
- 被催办展示信息：
  - 流程发起人名称+的+流程名称+申请催办
  - 若今天，展示今天+时间（时+分）
  - 若昨天及以前，展示日期+时间（时+分）

**催办限制规则**：

- 流程发起后即可催办
- 催办后5分钟内不可再次点击，点击提示：5分钟内仅可催办一次

**时效信息说明**：

- 发起时间：流程发起的完整时间（YYYY-MM-DD HH:mm:ss）
- 总耗时：流程从发起到当前的总时间（如"1天2小时15分钟"）
- 当前等待：当前审批节点的等待时间（如"15分钟"、"1天10分钟"）
