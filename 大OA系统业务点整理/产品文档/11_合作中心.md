# 11\_合作中心

## 1. 企业管理列表页面

### 一、页面要素说明

| 模块     | 说明                                                     |
| ------ | ------------------------------------------------------ |
| 面包屑导航  | 展示当前位置路径：合作中心 > 企业管理                                   |
| 搜索区域   | 提供企业筛选条件，共5个筛选项（企业名称、管理员姓名、管理员手机号、成员姓名、成员手机号），及查询、重置按钮 |
| 企业数据列表 | 以表格形式展示企业信息                                            |
| 分页控件   | 控制列表数据的分页展示                                            |

### 二、功能逻辑详情

#### （一）搜索筛选

##### 筛选项与筛选逻辑

| 筛选项名称  | 控件类型     | 匹配规则                                                                    |
| ------ | -------- | ----------------------------------------------------------------------- |
| 企业名称   | 可搜索下拉选择框 | 输入文本后自动触发搜索联想，展示匹配的企业名称下拉列表；也可点击下拉箭头展开列表，选中选项后触发搜索。输入内容与数据库中的企业名称进行模糊匹配 |
| 企业开户状态 | 下拉框      | 未开户、已开户                                                                 |
| 企业认证状态 | 下拉框      | 已认证、认证中、未认证                                                             |
| 管理员姓名  | 文本输入框    | 输入内容与企业的管理员姓名进行精准匹配                                                     |
| 管理员手机号 | 文本输入框    | 输入内容与企业的管理员手机号进行精准匹配                                                    |
| 成员姓名   | 文本输入框    | 输入内容与企业的成员姓名进行精准匹配                                                      |
| 成员手机号  | 文本输入框    | 输入内容与企业的成员手机号进行精准匹配                                                     |

##### 表格字段

| 字段名      | 说明                                                                                      |
| -------- | --------------------------------------------------------------------------------------- |
| 序号       | 行号，从1开始递增                                                                               |
| 企业名称     | 企业全称                                                                                    |
| 统一社会信用代码 | 18位统一社会信用代码。添加企业时天眼查查询返回                                                                |
| 企业开户状态   | 已开户 / 未开户 。添加、编辑企业时开户，开户后不可关闭，无需显示"销户"按钮。未开户无法录入管理员和成员信息。若添加企业时未开户，添加企业后，再添加管理员，该动作视为开户 |
| 企业认证状态   | 已认证 / 认证中 / 未认证 。发起后视为认证中，认证完成后视为已认证 。                                                  |
| 管理员      | 企业管理员姓名                                                                                 |
| 管理员手机号   | 企业管理员手机号码                                                                               |
| 操作       | 展示操作入口「详情」链接                                                                            |

##### 排序规则

**默认排序**：按创建时间倒序排列，最新创建的企业排在最前面。

**手动排序**：不支持手动切换排序维度。

##### 导出规则

- 导出时，导出所有企业数据。
- 导出文件格式：Excel。
- 导出文件名：企业列表.xlsx。
- 子项目名称仅可导出自己权限内的企业数据。顺序同列表。
- 注意，企业列表通过页面权限控制，关联的子项目通过用户权限控制。
- 导出字段：统一社会信用代码；企业名称；类型；子项目名称（多个用分号相隔）
- 命名以本文档为准。

##### 页面要素说明

| 模块   | 说明                      |
| ---- | ----------------------- |
| 弹窗标题 | 展示"添加企业"                |
| 表单区域 | 包含企业基本信息、管理员信息、成员信息录入字段 |

##### 字段清单

| 成员信息             | 选填     | 动态列表   | 支持多行添加，每行包含成员姓名和成员手机号，录入管理员后，方可录入成员信息 |

##### 成员信息字段

| 字段名   | 是否必填 | 控件类型  | 说明            |
| ----- | ---- | ----- | ------------- |
| 成员姓名  | 选填   | 文本输入框 | 成员姓名，最大长度50字符 |
| 成员手机号 | 选填   | 文本输入框 | 11位数字格式       |

##### 功能逻辑

**触发条件**：点击企业列表页面的「添加企业」按钮

**执行流程**：

1. 弹出添加企业表单弹窗
2. 用户填写企业名称（必填）、统一社会信用代码（反显）
3. 用户选择是否开户（必填）
4. 若选择「是」开户，则管理员姓名和管理员手机号变为必填项，否则不可录入
5. 用户可选择添加成员信息，点击「+」按钮添加新成员行，点击垃圾桶按钮删除成员行
6. 用户点击「提交」按钮，系统校验数据后保存

**业务结果**：

- 保存成功：关闭弹窗，刷新企业列表，新企业信息展示在列表中
- 保存失败：弹窗保持打开，提示错误信息，保留已填写数据
- 点击「取消」：关闭弹窗，不保存任何数据

**校验规则**：

- 企业名称：非空，不超过500字符
- 统一社会信用代码：非空，18位字母数字组合，唯一性校验
- 是否开户：必填，二选一
- 管理员姓名（开户时）：非空，不超过50字符
- 管理员手机号（开户时）：非空，11位数字格式
- 成员姓名：不超过50字符
- 成员手机号：11位数字格式（若填写）

##### 1. 管理员信息

反显管理员信息，管理员唯一。
若当前企业未开户，无管理员，展示按钮【新增管理员】，否则隐藏。
点击弹窗，可添加管理员，添加后，自动开户，且发送对应短信。
展示电子签章开通和关闭记录，包括时间、操作人、操作结果。按操作时间倒序。
若当前管理员电子签章未开通，后边展示按钮【开通】，否则展示按钮【关闭】。特殊情况，当该管理员未认证申请通过时，虽然电子签章状态是未开通，但不可操作【开通】，将电子签章状态改为已开通。此时按钮应该隐藏。只有第一管理员认证申请通过后，才展示【开通】或【关闭】按钮。

**结果说明**：

- 保存成功：页面退出编辑模式，管理员信息更新为新数据
- 保存失败：页面保持编辑模式，保留当前填写数据，提示错误原因
- 取消：页面退出编辑模式，字段恢复为修改前的数据

#### （四）企业征信信息（Tab 3）

企业征信信息 Tab 下设置两个次级 Tab，企业征信与企业授信分开管理、分别展示。

##### 1. 企业征信基本信息

展示当前企业的征信基本信息。

- 最新更新人和更新时间：取企业信息报送流程中审批通过后的流程发起人及审批通过时间。通过即覆盖下方表单内容。
- 关联审批单：展示当前企业的企业信息报送类所有流程，按发起时间倒序排列。包括所有状态
- 推送记录：仅展示企业信息报送类流程的推送记录。每次推送单独记录，按推送时间倒序排列；推送记录仅表示 OA 已发起推送，不等待或展示征信系统处理结果。
- 查看操作：进入对应流程详情页，并按当前用户权限判断是否允许查看。

##### 2. 企业授信基本信息

展示当前企业的授信信息，包含授信概览、授信列表和推送记录三个区域。

**授信概览**：展示最新授信审批单中的授信额度、授信额度编号、最新审批单更新时间、更新人。点击【展示最新审批单表单内容】可查看该授信审批单的完整表单信息。

**授信列表**：按子项目展示授信记录，默认按授信信息更新时间倒序排列。

| 字段      | 说明               |
| ------- | ---------------- |
| 序号      | 当前列表序号           |
| 授信子项目   | 授信所属子项目名称        |
| 项目名称    | 授信所属项目名称         |
| 授信额度（元） | 当前授信额度，按金额格式展示   |
| 可用额度（元） | 当前剩余可用授信额度       |
| 授信起止日期  | 授信生效日期至授信到期日期    |
| 授信状态    | 启用、到期、失效等当前状态    |
| 操作      | 点击【查看】进入对应授信流程详情 |

**推送记录**：展示当前企业的授信类流程推送记录，默认按推送时间倒序排列。

| 字段       | 说明                     |
| -------- | ---------------------- |
| 序号       | 当前列表序号                 |
| 流程编号     | 授信报送流程编号               |
| 项目/子项目名称 | 流程所属项目及子项目名称           |
| 流程类型     | 授信报送流程类型               |
| 时点       | 授信开始、额度调整、授信到期/失效等报送时点 |
| 信息报告日期   | 本次授信信息对应的报送日期          |
| 推送人      | 发起推送的操作人               |
| 推送时间     | 实际推送时间，精确到秒            |
| 操作       | 点击【查看】进入对应流程详情         |

**分页规则**：授信列表和推送记录分别分页，展示总条数，默认每页10条，支持页码、上一页、下一页和每页条数切换。

**数据规则**：授信信息按子项目独立管理，同一企业不同子项目的授信信息不得合并；授信数据取审批通过的授信类流程，审批中的流程不更新授信概览及授信列表。

##### 授信详情

授信信息详情内不仅包括授信信息，还包括具体的审批单和推送记录。也就是该条信息的审批单和推送记录。

###### 2.1 关联审批单

**数据来源与关系**：数据来源于流程管理中发起的授信类流程。每条授信流程发起时，必须关联一个项目和一个子项目；流程审批通过后，该流程形成当前子项目的一条授信记录。授信详情页的“关联审批单”通过授信记录与授信流程的关联关系查询，不新增或复制流程数据。

展示当前授信记录关联的授信类流程，包含所有审批状态，默认按发起时间倒序排列。

| 字段       | 说明                                |
| -------- | --------------------------------- |
| 序号       | 当前列表序号                            |
| 流程编号     | 关联授信流程的编号                         |
| 项目/子项目名称 | 流程所属项目及子项目名称                      |
| 流程类型     | 授信报送流程类型                          |
| 时点       | 授信开始、额度调整、授信到期/失效等报送时点            |
| 信息报告日期   | 该流程对应的信息报告日期                      |
| 发起人      | 流程发起人姓名                           |
| 审批状态     | 当前流程审批状态                          |
| 操作       | 点击【查看】进入流程详情页；无权限时不可查看，并按系统统一规则提示 |

**数据范围**：仅展示与当前授信记录所属子项目关联的授信类流程，不展示其他企业、项目或子项目的流程。仅一条

###### 2.2 推送记录

**数据来源与关系**：数据来源于授信流程的推送操作。每次对与当前授信记录关联的授信流程执行推送，系统生成一条推送记录，并通过授信流程编号与当前授信记录关联；推送记录不由用户手工新增或编辑。

展示当前授信记录对应的全部推送记录。每次推送单独生成一条记录，同一流程多次推送时展示多条，默认按推送时间倒序排列。

| 字段       | 说明                     |
| -------- | ---------------------- |
| 序号       | 当前列表序号                 |
| 流程编号     | 被推送授信流程的编号             |
| 项目/子项目名称 | 流程所属项目及子项目名称           |
| 流程类型     | 授信报送流程类型               |
| 时点       | 授信开始、额度调整、授信到期/失效等报送时点 |
| 信息报告日期   | 本次推送对应的信息报告日期          |
| 推送人      | 发起推送的操作人姓名             |
| 推送时间     | 实际推送时间，精确到秒            |
| 操作       | 点击【查看】进入对应流程详情页        |

**数据规则**：推送记录仅表示系统已发起推送，不等待或展示征信系统处理结果；列表查看权限沿用当前企业详情的流程查看权限规则。

##### 3. 企业征信与授信流程规则

**企业征信基本信息**：同一企业只需报送一次企业信息；后续更新以企业为维度，可跨项目选择，只要该企业已发生过业务即可进行企业信息更新报送。同一企业存在企业信息报送在途流程时，不允许重复发起，提示「该企业存在过程中流程，请勿重复发起」。企业信息报送流程审批通过后，数据同步至“企业征信基本信息”次级 Tab。

**企业授信基本信息**：授信按子项目独立报送。每个子项目的多次放款产生的授信信息均归属于该子项目；发起授信更新时，只能选择该子项目内的授信报送流程，不得跨项目或跨子项目选择。授信流程审批通过后，数据同步至“企业授信基本信息”次级 Tab。
