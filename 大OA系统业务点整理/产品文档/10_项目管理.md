1. 弹出高级搜索弹窗

### 1.2 列表展示

#### 表格字段

| 序号 | 字段名        | 说明                        | 示例值          |
| -- | ---------- | ------------------------- | ------------ |
| 1  | 序号         | 行号，从 1 开始递增               | 1            |
| 2  | 项目名称       | 项目全称                      | AAA项目        |
| 3  | 子项目名称      | 子项目全称，无子项目时为空             | xxxx项目       |
| 4  | 业务类型       | 子项目所属业务类型                 | 直保理 / 再保理    |
| 5  | 子项目状态      | 子项目当前所处状态                 | 已立项          |
| 6  | 子项目融资金额（元） | 以千分位格式展示，无子项目时为空          | 151,000.00   |
| 7  | 是否征信报送     | 子项目是否需要征信报送               | 是 / 否        |
| 8  | 操作         | 项目行展示「进入项目」，子项目行展示「进入子项目」 | 进入项目 / 进入子项目 |

#### 表格行展示逻辑

**一个项目在列表中可能对应多行数据**：

- **项目行**：仅显示项目名称和序号，操作列显示「**进入项目**」。子项目名称、业务类型、子项目状态、子项目融资金额、是否征信报送字段均为空。
- **子项目行**：每个子项目单独一行。项目名称列显示所属项目名称，子项目名称列显示子项目名称，操作列显示「**进入子项目**」。
- **同一项目下的多行**：第一行为项目行（点击进入项目详情），后续行为该项目的子项目行。每行有独立的分隔线。按创建时间倒序排列。从上到下的顺序对应项目内从左到右的顺序。

**交互说明**：

- 点击「**进入项目**」：跳转到项目详情页，查看项目信息和该项目下所有子项目
- 点击「**进入子项目**」：跳转到项目详情页，默认定位到对应子项目 Tab
- 分页按项目展示，每个项目及其全部子项目作为一个分页单元，不拆分到不同页面；总条数按项目数量统计。无子项目的项目仍展示项目行。

#### 业务规则

- **只有立项审批完成的项目才在列表中展示**
- **项目发起人默认为项目经理**
- **用户只能看到有权限的项目/子项目数据**

### 1.3 导出

**触发条件**：点击「导出」按钮

**执行流程**：

1. 获取当前筛选条件
2. 调用后端导出 API
3. 生成 Excel 文件并下载。走下载中心。

**注意**：

- 记录每个用户的操作，进入默认展示上次该用户的勾选记录

**导出规范**：

- 导出勾选数据
- 导出文件格式：Excel
- 导出文件名：项目信息表.xlsx
- 仅导出用户有权限的项目/子项目数据
- 支持全选
- 导出字段可配置

#### 导出项目信息表弹窗

**页面布局描述**：

弹窗用于选择需要导出的项目，并配置本次导出的字段和附件。页面分为左侧项目筛选及项目列表区域、右侧导出配置区域和底部导出操作区域。

1. 左侧项目筛选区域：用于按项目及子项目条件筛选可导出的数据。
2. 左侧项目列表区域：展示符合筛选条件且当前用户有权限查看的项目及子项目，支持勾选导出对象。
3. 右侧导出配置区域：按字段分组展示可导出的字段，支持展开、收起和全选。
4. 底部导出操作区域：展示已选项目数、已选字段数、已选附件数，并提供“开始导出”按钮。

**筛选项**：

| 字段名 | 类型 | 是否必填 | 默认值 | 筛选规则 |
| --- | --- | --- | --- | --- |
| 项目名称 | 文本输入 | 否 | 空 | 按项目名称进行模糊匹配；输入后点击“查询”生效。 |
| 子项目名称 | 文本输入 | 否 | 空 | 按子项目名称进行模糊匹配；输入后点击“查询”生效。 |
| 业务类型 | 下拉单选 | 否 | 全部 | 选项来源于系统已配置的业务类型，按子项目业务类型精确筛选。 |
| 项目状态 | 下拉单选 | 否 | 全部 | 按项目当前状态精确筛选，选项来源于项目状态枚举。 |
| 是否征信报送 | 下拉单选 | 否 | 全部 | 选项为“是”“否”；按项目或子项目是否已配置征信报送进行筛选。 |
| 归档状态 | 下拉单选 | 否 | 全部 | 按项目归档状态精确筛选，选项为“已归档”“未归档”。 |

**项目列表**：

| 列名 | 类型 | 展示及交互规则 |
| --- | --- | --- |
| 选择 | 复选框 | 用于选择需要导出的项目；支持当前页全选。 |
| 项目名称 | 文本 | 展示项目名称；同一项目下的子项目按项目分组展示。 |
| 子项目名称 | 文本 | 展示项目对应的子项目名称；无子项目时展示“—”。 |
| 业务类型 | 文本 | 展示子项目所属业务类型；无子项目时展示“—”。 |
| 所属部门 | 文本 | 展示项目或子项目所属部门；无数据时展示“—”。 |

**项目列表规则**：

1. 列表仅展示当前用户有权限查看且已完成立项审批的项目及其子项目。
2. 项目名称、子项目名称、业务类型、所属部门按照当前数据展示；项目不存在子项目时仍展示项目行。
3. 默认按项目创建时间倒序排列；同一项目下的子项目按子项目创建时间倒序排列。
4. 查询后列表仅保留同时满足全部已填写筛选条件的数据；多个筛选条件之间使用“且”关系。
5. 未查询到数据时，列表展示空状态“暂无符合条件的项目”。
6. 列表支持分页，展示总条数、当前页、每页条数和页码；切换筛选条件并点击“查询”后，分页重置为第1页。
7. 切换页面、修改筛选条件或点击“重置”时，不清除已在其他页面选中的项目；已选项目数量按实际勾选结果实时更新。
8. 当前页全选只选择当前查询结果页中的项目；取消当前页全选只取消当前页项目，不影响其他页面已选项目。

**导出配置区域规则**：

1. 字段按业务分组展示，分组支持展开和收起；展开时展示该分组下的可选字段。
2. 点击分组“全选”时，选中该分组全部字段；再次点击时取消该分组全部字段。
3. 已选字段数量实时展示在分组标题和底部汇总区域；未选择任何字段时，“开始导出”按钮不可用。
4. 附件字段按附件类型单独选择；选择附件字段后，系统按照已有附件导出规则生成对应文件或文件夹。
5. 用户上次保存的字段选择结果作为下次打开弹窗时的默认勾选结果；首次使用时按系统默认字段展示。

**操作按钮**：

| 按钮 | 触发条件 | 操作逻辑 |
| --- | --- | --- |
| 查询 | 点击按钮 | 按当前筛选条件刷新项目列表，分页回到第1页；已选项目不因查询刷新而自动清除。 |
| 重置 | 点击按钮 | 清空项目名称、子项目名称、业务类型、项目状态、是否征信报送和归档状态，恢复默认列表并回到第1页；已选项目保持不变。 |
| 全选 | 点击列表区域“全选” | 选中当前页全部项目；若当前页项目均已选中，则取消当前页全部项目。 |
| 开始导出 | 已选择至少1个项目且至少选择1个字段 | 按已选项目、已选字段及附件配置生成 Excel 或附件压缩包，提交至下载中心；导出完成后保留本次选择记录。 |
| 关闭 | 点击关闭图标或取消操作 | 关闭弹窗，不执行导出；本次未提交的筛选条件和字段变更不作为下次默认配置。 |

**数据规则与异常处理**：

1. 导出数据范围受项目、子项目和字段权限控制，用户无权限查看的数据不得出现在项目列表或导出文件中。
2. 项目被删除、撤销立项或权限在弹窗打开后发生变化时，点击“开始导出”重新校验；不符合条件的数据不导出，并提示“部分项目已无权限或已不可导出，请重新选择”。
3. 已选项目在查询后不再满足筛选条件时，保留其已选状态，但导出时仍以当前用户权限和最新项目状态为准。
4. 导出过程中发生失败时，不生成不完整文件；下载中心记录失败状态及失败原因。

**导出 Excel 展示规则**：

1. Excel 采用横向对比结构，在同一工作表中展示本次勾选范围的数据：每个已选导出字段占一行，每个子项目占一列。
2. 第一列固定为“字段名称”；自第二列起展示子项目，列表头以“项目名称 / 子项目名称”标识归属，不受是否勾选名称字段影响。名称字段被勾选时，仍作为独立字段行展示。
3. 字段行按照导出弹窗中的字段分组及组内顺序生成，仅展示已勾选字段；每个单元格展示该字段在对应子项目下的字段值。不同分组存在同名字段时，字段名称增加分组前缀以便区分。
4. 同一项目的子项目列相邻排列，不同项目依次向右展开；项目及其子项目顺序沿用弹窗列表的默认排序。数据列数按本次实际导出的子项目总数生成，不按单个项目的最大子项目数量截取。勾选的项目没有子项目时，保留一个项目列，表头为“项目名称 / 无子项目”，仅展示项目级字段值，子项目级字段留空。
5. 项目级字段在该项目下的所有子项目列中重复展示相同值；子项目级字段分别展示各子项目自身的数据。
6. 项目成员、担保主体等多值字段在同一单元格内换行展示。“收入方式”和“关联子项目”的多组明细按原记录顺序编号，并展开为独立字段行，例如“收入方式1-收入类型”“收入方式1-费率/利率/折扣率”“收入方式1-收入方式说明”“收入方式2-收入类型”，以及“关联子项目1-子项目名称”“关联子项目1-关联关系”。两类明细分别取本次导出子项目中的最大明细数量，按序号重复生成已勾选字段行；不足的单元格留空，全部无明细时保留一组已勾选字段行，值留空。
7. 勾选附件字段时，Excel 对应字段行展示附件名称，多个附件在同一单元格内换行展示；附件文件仍按照上方“附件信息”约定的文件夹及命名规则导出。

##### 9. 实际还款信息

展示当前子项目下的实际还款记录，默认按实际还款日期倒序；实际还款日期相同时，按最后编辑时间倒序。

1. 点击"编辑"可修改付款计划；可任意修改，每次修改记录一次快照。编辑时不仅可修改导入的信息，还可以编辑关联的付款流程。编辑时需匹配限制规则，不能把多个生效的付款流程关联进来。实际付款日和付款金额取关联流程的值，关联后失焦生效。最终结果以付款计划编辑页面的保存按钮为准。
2. 点击"发起放款"可基于该付款计划信息发起放款流程，携带参数进入资金支付流程。
3. **付款计划台账**：仅记录付款计划编辑操作。用户修改付款计划、计划明细、关联付款流程或备注并保存成功后，生成一条台账记录；新增付款计划、删除付款计划、发起放款及其他操作不写入付款计划台账。台账字段包括序号、操作人、操作时间、操作类型、备注、操作；操作类型固定为“付款计划调整”。点击“查看历史记录”展示该次编辑保存后的付款计划数据快照。台账按操作时间倒序展示，记录生成后不可修改或删除。
4. **详情页底部操作**：
   - 点击"删除"删除当前付款计划；点击"返回"回到付款计划列表。
   - 点击删除时检测是否存在关联的流程，若存在，提示：当前付款计划已关联付款流程，不建议删除，请确认您的操作。取消/确认删除。
   - 确认删除后，继续弹窗提示：确认删除该付款计划？取消/确认删除。
   - 仅逻辑删除，统计时不统计已删除的付款计划。

##### 12. 存续期管理报告

展示当前子项目的存续期管理报告文件和管理概述。

1. 支持上传、查看、删除报告文件；文件格式不限，单个文件最大500MB。
2. 多个管理报告对应一份管理概述，管理概述支持编辑，最大2000字。
3. 报告列表字段包括序号、文件名、上传人、上传时间、操作。
4. 删除文件需二次确认；上传、删除、编辑均写入子项目信息修改记录。
5. 项目概览中的“存续期管理报告”状态根据是否存在报告文件展示“已上传/未上传”。

##### 13. 外部机构

展示并维护当前子项目的外部机构信息，点击“编辑”后进入编辑状态。

| 字段     | 类型   | 必填 | 规则     |
| ------ | ---- | -- | ------ |

| 律师事务所  | 文本输入 | 否  | 最大200字 |
| 评级公司   | 文本输入 | 否  | 最大200字 |
| 会计师事务所 | 文本输入 | 否  | 最大200字 |
| 其他资金方  | 文本输入 | 否  | 最大200字 |

**交互规则**：

1. 进入编辑状态时反显当前已保存信息；字段允许新增、修改或清空。
2. 点击“保存”校验字段长度，校验通过后整体保存并返回查看状态；字段清空后保存，视为删除该项机构信息。
3. 点击“取消”放弃本次修改并恢复保存前内容；存在未保存修改时，点击取消或离开页面需二次确认。
4. 保存后，已填写的机构可在对应外部机构的项目管理列表中查看当前子项目；字段被清空后，该机构不再通过此关联查看当前子项目。
5. 当前子项目资产列表按已维护的机构类型展示相应审核结果。
6. 每次保存按字段记录差异，格式为“外部机构修改：律师事务所由‘A’变更为‘B’”；新增和清空分别记录为“新增”和“删除”。

##### 14. 关联子项目

用于维护当前子项目与其他项目或当前项目下其他子项目的关联关系。点击“编辑”后进入编辑状态，支持维护多条关联记录。

| 字段    | 类型   | 必填 | 规则                                   |
| ----- | ---- | -- | ------------------------------------ |
| 子项目名称 | 下拉选择 | 是  | 可跨项目选择，仅展示当前用户有权限查看且未删除的子项目；不展示当前子项目 |
| 关联关系  | 多行文本 | 是  | 最大2000字，实时展示已输入字数/2000               |

**交互规则**：

1. 进入编辑状态时反显已保存的全部关联记录；无记录时默认展示一条空白记录。
2. 点击行尾“+”在当前行下方新增一条空白记录；页面始终至少保留一条记录。
3. 存在两条及以上记录时展示删除图标；点击后删除当前行。删除已保存记录仅在点击“保存”后生效。
4. 同一被关联子项目只能添加一次；重复选择时提示“该子项目已关联，请勿重复添加”。
5. 关联子项目不得选择当前子项目；已在其他行选择的子项目在下拉选项中不可再次选择。
6. 点击“保存”时逐行校验：子项目名称和关联关系均必填；存在空白行、重复记录或字段超长时不保存，并定位提示对应行。
7. 保存成功后整体更新关联关系并返回查看状态；点击“取消”恢复保存前数据，存在未保存修改时需二次确认。
8. 新增、修改、删除分别写入修改记录。例如：“关联子项目新增：子项目名称=项目A，关联关系=共同融资”；“关联子项目修改：项目A的关联关系由‘共同融资’变更为‘资产关联’”；“关联子项目删除：子项目名称=项目A，关联关系=资产关联”。

##### 15. 子项目成员

1. 支持手动新增营销经理成员；此处成员与子项目基本信息中的营销经理字段相互独立。
2. 每个子项目单独维护成员列表，营销经理成员权限与干系人权限一致。

5. 文件名称、流程编号、还款计划编号、付款计划编号及关联子项目名称以链接形式展示。点击文件名称在线预览，格式不支持预览时下载；点击流程编号、计划编号或子项目名称进入对应详情页。
6. 删除文件时保留删除前文件及其关联关系，操作事项中的文件名称仍可点击查看或下载；逻辑删除还款计划、付款计划后，点击计划编号展示删除操作发生前的只读详情快照，不允许编辑、恢复或继续发起业务。
7. 点击链接前校验当前用户数据权限；无权限时不打开详情并提示“暂无权限查看该信息”。文件不存在、损坏或存储服务异常时提示“文件暂时无法查看，请稍后重试”，不得影响其他操作记录展示。
8. 操作记录按操作时间倒序展示；记录生成后不可修改或删除。操作事项内容超出列表可展示范围时自动换行并完整展示，不使用省略号；列表不分页。

**编辑说明**：

- 字段支持编辑，子项目基本信息区域可直接修改；项目名称不可修改。
- 字段较多时按逻辑分组展示。

**统一确认弹窗规则**：

| 触发场景                | 提示文案                               | 按钮及结果                                       |
| ------------------- | ---------------------------------- | ------------------------------------------- |
| 编辑后未保存，点击取消、关闭或离开页面 | 内容未保存，退出将丢失全部修改，确认退出？              | “返回”：关闭提示并继续编辑；“退出”：放弃本次全部修改，恢复保存前数据并退出编辑状态 |
| 点击保存且校验通过           | 请确认是否提交保存当前修改内容，提交后数据将覆盖原有记录，无法撤回。 | “返回修改”：关闭提示并继续编辑；“确认”：保存全部修改并覆盖当前记录         |
| 修改子项目状态并点击保存        | 是否确认修改该子项目状态？                      | “返回”：关闭提示，不修改状态；“确认”：保存新状态并记录状态变更           |

1. 保存前先执行必填、格式、长度及业务规则校验；校验不通过时不打开提交确认弹窗，直接定位并提示错误字段。
2. 用户确认保存后，以本次页面提交内容整体更新对应信息；保存成功后退出编辑状态并刷新页面。
3. 保存失败时保留当前编辑内容并提示失败原因，不得覆盖原有数据。
4. 未发生任何字段变化时点击保存，不生成修改记录，可直接退出编辑状态。
5. 子项目状态变更记录格式为"子项目状态：由'原状态'变更为'新状态'"，记录操作人和操作时间。

##### 手动关联流程

1. 在子项目「流程信息」Tab 提供【关联流程】入口，具备当前子项目关联操作权限的用户可打开弹窗。此入口关联已有流程，与【发起申请】自动归属当前子项目分开处理。
2. 仅展示当前主体内用户有查看权限的已发起流程。已自动或手动关联当前子项目的流程不可重复选择；确认时再次校验权限及重复关联，失效时不提交并提示原因。
3. 关联仅建立当前子项目下的查看入口，不修改流程内的项目、子项目、表单、审批状态、审批人员或历史版本，不改变业务归属，不计入当前子项目的资金、资产、授信等业务统计，不使该流程成为当前子项目征信业务的可选来源。
4. 流程原属其他子项目不因本次查看关联而迁移；用户仍须具有原流程查看权限，关联不授予新权限。同一流程可供不同子项目查看，在同一子项目中只展示一次。

1. 仅当流程与当前子项目的关系为手动关联，且用户具备解除关联权限时，展示【取消关联】。发起时自动关联的流程不展示该按钮，不允许通过手动关联覆盖自动关联来源。
2. 手动关联仅用于查看，取消不受流程审批状态限制；审批中、办结中及已结束流程均按手动来源和操作权限判断。
3. 点击后提示「确认取消该流程与当前子项目的关联？」，提供【取消】【确认取消】。取消不改变数据；确认时再次校验当前用户操作权限及该关联是否仍为手动关联，仅通过后解除本次查看关联，写入一条「取消关联」记录并刷新列表。若操作权限已失效、该关系不是手动关联或已解除，分别提示「您无权取消该关联」「仅可取消手动关联的流程」「该关联已取消，请刷新列表」，不变更关联、不新增操作记录。
4. 不删除流程、不修改其业务归属和审批记录，不影响其他子项目的关联。取消后可重新手动关联，每次成功操作分别记录；失败时保留原关联及列表并提示原因。

##### 流程关联记录

在子项目「流程信息」Tab 提供【关联记录】入口，用户具有当前子项目流程信息查看权限时可打开弹窗；记录范围按下述数据权限过滤。与“关联子项目”业务的修改记录区分。

| 字段 | 展示规则 |
| ---- | ---- |
| 序号 | 按当前排序展示 |
| 流程编号 | 操作对应的流程编号 |
| 流程类型 | 操作时的流程类型 |
| 审批状态 | 操作发生时的审批状态，后续状态变化不改写该历史值 |
| 操作 | 关联、取消关联 |
| 操作人 | 实际执行操作的用户，保留操作时姓名 |
| 操作时间 | 成功操作时间，精确到秒 |
| 操作：查看 | 当前仍有该流程查看权限时展示，点击进入流程详情；无权限不展示入口 |

1. 每次成功手动关联、取消关联均生成一条记录，批量关联按流程分别记录；反复关联和取消不合并，不删除历史记录。自动发起归属不记为手动关联。
2. 记录按操作时间倒序，默认每页5条，支持调整每页条数及跳页；无记录展示「暂无关联记录」。【关闭】或右上角关闭仅关闭弹窗。
3. 记录限定当前子项目及用户可查看的流程范围；取消关联后记录仍保留，用户仍有流程权限时可以查看。不得因历史关联绕过当前流程权限。
4. 记录为只读，不提供修改、删除入口。操作失败或取消确认不生成成功记录。

##### 发起申请

1. 点击右上角“发起申请”，打开流程类型选择或流程发起页面。
2. 仅展示当前用户有权限发起、且允许关联当前子项目的流程类型。
3. 发起流程时自动带入当前项目和子项目信息，用户不得将流程关联到其他项目或子项目。
4. 发起成功后，流程自动关联当前子项目，返回流程信息 Tab，列表刷新并按最新发起时间展示新流程。
5. 发起失败时保留当前页面及筛选条件，提示失败原因，不新增流程卡片。
6. 无流程发起权限时不展示“发起申请”按钮。

##### 流程卡片

流程卡片采用双列排列，每张卡片独立展示一条流程。卡片左侧展示竖向审批状态标识，右侧展示流程信息和操作。

| 字段       | 展示规则                                     |
| -------- | ---------------------------------------- |
| 审批状态     | 展示在卡片左侧；状态包括审批中、办结中等，状态文字竖向排列            |
| 流程标题     | 按“{发起人}提交的【流程名称】”格式展示，例如“张三三提交的【项目资金划付】” |
| 流程编号     | 展示系统生成的流程编号，例如“ZJHF2025111700001”        |
| 发起时间     | 展示流程发起时间，格式：YYYY-MM-DD HH:mm:ss          |
| 项目/子项目名称 | 展示流程所属项目及子项目名称                           |
| 款项类别     | 展示流程对应款项类别；无值时展示“--”                     |
| 金额（元）    | 展示流程金额，保留两位小数；无金额时展示“--”                 |
| 总耗时      | 展示从流程发起至当前时间或流程结束时间的耗时                   |
| 当前等待     | 展示当前审批节点已等待时长；流程结束后展示“--”                |
| 当前处理人    | 展示当前审批节点处理人；无当前处理人时展示“--”                |

##### 流程卡片操作

| 操作   | 触发条件                 | 操作结果                                    |
| ---- | -------------------- | --------------------------------------- |
| 取消关联 | 仅手动关联且用户具备解除关联权限，不受审批状态限制 | 弹出二次确认；确认后解除流程与当前子项目的关联，不删除流程本身，成功后刷新列表 |
| 查看   | 用户具备流程查看权限           | 进入流程详情页；无权限时不展示入口                       |

流程卡片不在本页面直接展示“撤销”和“催办”操作；如流程详情页支持对应操作，以流程详情页的状态和权限规则为准。

##### 审批状态

| 状态  | 展示及操作规则                             |
| --- | ----------------------------------- |
| 审批中 | 流程正在审批；按截图使用橙色状态标识，仅手动关联且有权限时可取消关联，或进入详情查看     |
| 办结中 | 审批已通过但后续办理未完成；按进行中状态展示，仅手动关联且有权限时可取消关联，或进入详情查看 |
| 已完结 | 流程全部办理完成；保留查看入口，仅手动关联且有权限时允许取消关联             |
| 已拒绝 | 审批被拒绝；保留查看入口，仅手动关联且有权限时允许取消关联                |
| 已撤销 | 流程已撤销；保留查看入口，仅手动关联且有权限时允许取消关联                |
| 已作废 | 流程已作废；保留查看入口，仅手动关联且有权限时允许取消关联                |

##### 排序、分页与异常

1. 默认按流程发起时间倒序排列；发起时间相同时按流程编号倒序排列。
2. 列表采用双列卡片展示，不改变流程数据的排序顺序；从左到右、从上到下依次排列。
3. 默认每页展示 10 条，截图示例共 9 条时显示“共 9 条”和第 1 页；支持切换每页条数、上一页、下一页和跳转页码。
4. 查询或重置后回到第 1 页；当前页无数据时自动回到最后一个有效页。
5. 无流程数据时展示“暂无流程数据”；不展示流程卡片。
6. 列表加载失败时展示重试入口，重试不清空筛选条件。
7. 取消关联失败时保留原卡片和当前筛选条件，提示失败原因。
8. 点击“返回”回到上一级页面，不修改流程及其关联关系。

##### 数据权限

- 仅展示当前子项目下已关联且用户有权限查看的流程。
- 取消关联只解除当前子项目与流程的关联，不删除流程数据及流程审批记录。
- 流程状态、流程编号、发起时间、审批节点和当前处理人以流程中心最新数据为准。

##### 手动关联验收要点

| 场景 | 预期结果 |
| ---- | ---- |
| 选择流程及确认期间查看权限失效 | 不允许关联无权限流程，不因关联取得流程查看权限 |
| 自动关联与手动关联流程同时展示 | 自动关联不展示取消按钮；手动关联且有权限时展示，不按审批状态限制 |
| 取消确认时关联来源或操作权限已不符合条件 | 阻止操作，不删除自动关联，不生成成功记录 |
| 手动关联其他子项目的流程 | 仅增加查看入口，流程内项目/子项目及业务信息不变，不参与目标子项目业务计算 |
| 同一流程重复关联当前子项目 | 阻止重复关联，列表只展示一次，不重复写入记录 |
| 关联、取消、再次关联 | 每次成功操作各记一条，取消后原记录仍保留，其他子项目关联不受影响 |
| 查看关联记录 | 展示操作时的状态、操作人及时间；流程详情仍按当前权限校验 |

| 详情     | 列表存在对应企业          | 进入企业资信详情页，展示企业基本信息、开户信息、认证信息、征信信息、企业信息和成员信息 |

##### 企业信息列表

| 企业征信状态 | 状态    | 展示未查询、查询中、正常、存在异常               |

状态用圆点和文字展示：异常、未完成类使用红色；已完成及正常使用绿色；查询中使用橙色；无数据使用灰色。状态颜色仅用于识别，不改变状态本身。

##### 资信状态查询规则

1. 点击“查询资信状态”后，进入当前子项目的企业征信查验页；该操作不调用外部资信接口，不生成查验历史记录。
2. 企业征信查验页中的“获取最新数据”才发起外部资信查询，并更新企业征信状态、征信结果更新时间和查询记录。
3. 用户具备企业资信查看权限时可进入企业征信查验页；具备企业资信查询权限时，才展示并可点击“获取最新数据”。
4. 进入查询页不影响正在执行的查询任务；查询任务执行期间，仅“获取最新数据”按钮禁用，不影响企业信息列表查看。

##### 企业征信查验

企业征信查验用于获取当前子项目关联企业的最新外部资信数据，并按查验结果区分异常企业与无异常企业。

**页面功能区**：

| 功能区    | 功能说明                                          |
| ------ | --------------------------------------------- |
| 企业名称搜索 | 输入企业名称，按名称模糊匹配查验记录                            |
| 数据分类标签 | 包括“异常企业”和“无异常企业”；默认展示“无异常企业”，点击后切换列表数据并保留搜索条件 |
| 获取最新数据 | 对当前子项目下可查询企业发起最新资信数据获取任务                      |
| 全部导出   | 导出当前已筛选分类下的全部查验数据                             |
| 查验历史   | 查看单个企业的历次资信查验记录                               |
| 详情     | 查看单个企业当前查验结果及明细                               |

**查验列表字段**：

| 字段       | 类型    | 规则说明                                     |
| -------- | ----- | ---------------------------------------- |
| 序号       | 文本    | 按当前页展示顺序编号                               |
| 企业名称     | 文本/链接 | 企业全称，点击进入企业资信详情                          |
| 统一社会信用代码 | 文本    | 企业唯一社会信用代码；无值时展示“--”                     |
| 最新获取时间   | 日期时间  | 最近一次成功或失败获取资信数据的时间，格式：YYYY-MM-DD HH:mm   |
| 是否中国境内设立 | 是/否   | 根据企业主体信息展示“是”或“否”；信息缺失时展示“--”            |
| 经营异常     | 数字/状态 | 展示经营异常记录数量；0 为无异常，正整数为存在异常，未获取数据展示“--”   |
| 法律诉讼     | 数字/状态 | 展示法律诉讼记录数量；0 为无异常，正整数为存在异常，未获取数据展示“--”   |
| 被执行人     | 数字/状态 | 展示被执行人记录数量；0 为无异常，正整数为存在异常，未获取数据展示“--”   |
| 失信人      | 数字/状态 | 展示失信被执行人记录数量；0 为无异常，正整数为存在异常，未获取数据展示“--” |
| 操作       | 操作按钮  | “查验历史”“详情”                               |

**异常企业判定规则**：

1. 企业最新有效查验结果中，经营异常、法律诉讼、被执行人、失信人任一指标大于 0，归入“异常企业”。
2. 上述四项均为 0 且最新数据获取成功，归入“无异常企业”。
3. 未获取到最新数据、数据获取失败或存在缺失字段的企业不归入“无异常企业”；按异常企业规则展示，并在相应指标处展示“--”。
4. 企业分类以最新一次查验结果为准，查验历史不影响当前分类。

**获取最新数据**：

| 项目    | 规则                                                       |
| ----- | -------------------------------------------------------- |
| 触发条件  | 当前子项目存在企业且用户具备企业资信查询权限                                   |
| 查询范围  | 当前子项目下全部可查询企业；已在查询中的企业不重复提交                              |
| 进行中处理 | 按钮置为加载/禁用状态，页面提示“正在获取最新数据”；用户不可重复点击                      |
| 成功处理  | 更新企业最新获取时间、四项风险指标和企业分类；列表自动刷新                            |
| 失败处理  | 保留最近一次有效成功数据；若无历史成功数据，指标展示“--”；记录失败时间及原因，并在列表提示该企业数据获取失败 |
| 完成提示  | 成功后提示“获取最新数据成功”；部分失败时提示成功和失败企业数量，可通过查验历史查看失败原因           |

**全部导出**：

1. 点击“全部导出”导出当前企业分类、企业名称搜索条件下的全部数据，不受当前页每页条数限制。
2. 导出字段与查验列表字段一致，不包含“操作”列。
3. 导出格式为 Excel，文件命名：子项目名-企业资信查验-异常企业/无异常企业-YYYYMMDD.xlsx。
4. 无可导出数据时提示“暂无可导出数据”，不生成空文件。

##### 查验历史

点击企业列表中的“查验历史”，打开“查询历史”弹窗，展示该企业全部资信查验记录。弹窗为只读，不支持新增、编辑、删除或导出。

**弹窗字段**：

| 字段   | 类型   | 展示规则                                                                |
| ---- | ---- | ------------------------------------------------------------------- |
| 序号   | 数字   | 按查验时间倒序排列后，从 1 开始递增；翻页后按全量结果连续编号                                    |
| 查验人  | 文本   | 展示发起该次查验的用户姓名；系统自动任务展示“系统”                                          |
| 查验时间 | 日期时间 | 查验任务完成时间，格式：YYYY-MM-DD HH:mm:ss                                     |
| 查验结果 | 文本   | 按固定顺序拼接：法律诉讼数、被执行人数、失信人数、经营异常数；示例：`法律诉讼数:37;被执行人数:0;失信人数:0;经营异常数:0` |

**数据规则**：

1. 一次查验任务完成后生成一条历史记录，无论结果成功或失败均需留痕。
2. 查验成功时，“查验结果”展示本次返回的四类风险数量；数量为 0 时必须展示 `0`，不得展示“--”。
3. 查验失败时，“查验结果”展示“查验失败：失败原因”；未返回具体原因时展示“查验失败：暂未获取到失败原因”。
4. 同一企业的历史记录按查验时间倒序排列；查验时间相同时按记录创建时间倒序排列。
5. 历史记录为审计数据，后续企业数据更新不得覆盖或修改既有记录。
6. 用户仅可查看有权限子项目内企业的查验历史；无查看权限时不展示“查验历史”操作入口。

**分页规则**：

| 项目     | 规则                                      |
| ------ | --------------------------------------- |
| 总条数    | 弹窗底部展示“共 X 条”，X 为该企业全部查验历史记录数           |
| 默认每页条数 | 5 条/页                                   |
| 每页条数   | 支持切换，每次切换后回到第 1 页                       |
| 翻页     | 支持上一页、下一页、页码跳转；首页上一页禁用，末页下一页禁用          |
| 关闭     | 点击右上角“×”或底部“关闭”按钮关闭弹窗；关闭不影响已完成或进行中的查验任务 |

**空状态与异常处理**：

- 无查验历史时，列表区域展示“暂无查询历史”，分页区域不展示页码和跳转控件。
- 历史记录加载失败时展示“查询历史加载失败，请重试”，提供重试按钮；不关闭弹窗。
- 弹窗打开期间新增查验记录不自动插入当前列表，用户关闭后重新打开或手动刷新页面后获取最新记录。

**状态说明**：

- 绿色圆点：本次获取最新数据成功；风险指标为 0 时表示无对应风险记录。
- 红色圆点：数据获取失败、指标存在风险记录或数据异常；鼠标悬浮展示失败原因或异常说明。
- “--”：尚无可展示的数据，不等同于 0。

##### 分页及数据规则

- 列表底部展示总条数、当前页、上一页、下一页、每页条数和跳转页码，默认每页 10 条。
- 查询或重置后分页回到第 1 页；切换每页条数后重新加载第 1 页。
- 默认按企业名称升序排列；同名企业按企业唯一标识排序。
- 仅展示当前子项目关联且用户有权限查看的企业；已解绑或已逻辑删除企业不展示。
- 企业角色、开户状态、认证状态、征信状态及企业信息录入状态均取当前最新状态。
- 企业信息列表与子项目概览中的企业数量统计保持一致。

##### 异常与边界

- 无企业数据时展示空列表和“暂无企业信息”，查询资信状态按钮不可用。
- 查询条件格式不正确时，在对应字段提示错误，不发起查询。
- 查询过程中离开页面，已提交的查询任务继续执行，返回页面后展示最新状态。
- 企业已被其他流程锁定或正在更新时，详情页允许查看，编辑类操作提示“企业信息正在处理中，请稍后重试”。
- 用户无查看权限时不展示企业信息 Tab；无详情权限时列表仍可按授权字段展示，详情按钮隐藏。

#### 2.4.6 归档信息

归档信息用于集中管理当前子项目的归档结果、归档文件和归档操作记录。归档文件分为一键自动归档文件和人工上传文件；自动归档完成后，用户仍可调整文件所属分类。所有归档相关操作均需记录操作人、操作时间和操作事项。

##### （1）归档结果

页面展示当前子项目的归档结果文件和归档状态。

**归档结果字段**：

| 字段名         | 说明                                                       |
| ----------- | -------------------------------------------------------- |
| 档案移交清单（签字版） | 展示当前子项目的档案移交清单文件，支持查看、下载、删除和上传。仅支持一个文件，若重复上传需要先删除原已上传文件。 |
| 归档状态        | 展示当前子项目归档状态，状态包括未归档、归档中、归档完成。                            |
| 操作          | 支持修改归档状态。归档完成状态下仍保留查看和下载文件权限；允许再次修改状态。                   |

**档案移交清单规则**：

1. 档案移交清单（签字版）由用户手动上传，不由一键归档自动生成。
2. 文件不存在时展示“上传”入口；上传成功后展示文件名，并记录上传人和上传时间。
3. 用户可删除当前文件后重新上传；删除、上传和替换均记录操作日志。
4. 文件仅支持当前用户权限范围内的查看、下载和删除操作。
5. 上传、删除或替换档案移交清单不改变当前归档状态。

##### （2）归档文件分类

点击一键归档，将正向结束的流程（审批通过，办结的流程，不是撤销，拒绝，作废的）里的文件，按分类进行归档。

归档文件区域按以下五类展示，每类独立维护文件列表。其中，一键自动归档仅处理第一类、第二类和第五类；第三类、第四类仅支持人工维护，不参与一键自动归档。

| 分类          | 归档范围                  |
| ----------- | --------------------- |
| 一、立项审批及决议文件 | 立项流程的所有附件、审核标准确认的所有附件 |
| 二、核心企业主体资料  | 征信流程的所有附件（所有征信流程）     |
| 三、保理端文件     | 不参与一键自动归档；            |
| 四、计划端文件     | 不参与一键自动归档；            |
| 五、其他签署及交付文件 | 用印流程的所有附件             |

**分类文件列表字段**：序号、文件名、上传时间、操作。

**文件操作**：

| 操作 | 触发条件          | 操作结果                                                  |
| -- | ------------- | ----------------------------------------------------- |
| 查看 | 点击文件操作“查看”    | 打开文件预览或详情；不支持预览的文件提供下载。                               |
| 下载 | 在支持下载的文件上执行下载 | 下载当前文件。                                               |
| 移动 | 点击“移动”        | 打开“移动文件至”弹窗，展示当前文件名和可选目标分类；选择目标分类并确认后，将文件从原分类移动至目标分类。 |
| 删除 | 点击“删除”        | 弹出二次确认；确认后从当前归档分类移除文件，并记录删除操作。                        |

**自动归档**：

1. 点击归档文件区域的“一键归档”，系统从当前子项目已完成的流程提取第一类、第二类和第五类可归档文件；第三类、第四类不参与本操作。
2. 系统按照预设归档规则将文件自动放入对应分类；已存在相同文件时不重复归档。多次点击一键归档，比对文件内容，不同则可归档，注意比对全部，而不是具体分类下的。
3. 自动归档完成后仅刷新各分类文件列表，不自动修改归档状态。
4. 自动归档产生的文件仍可通过“移动”操作调整所属分类，移动后文件内容不变，仅变更归档分类。
5. 自动归档成功、部分成功或失败均需轻提示。
6. 一键归档、移动及导出文件均与归档状态相互独立，不触发归档状态自动变更。

**归档文件导出**：点击归档文件区域的“导出”，按五类目录结构导出当前子项目的全部自动归档文件；导出文件保留原文件名和分类目录，走下载中心，命名：子项目名-归档文件-日期

##### （3）外部机构归档文件（手动归档）

用于人工上传一键归档无法自动获取的外部机构文件，与前述五类自动归档文件分开管理。

**列表字段**：序号、文件名、上传人、上传时间、操作。

**功能规则**：

1. 点击“上传”选择本地文件，可一次上传一个或多个文件；上传成功后生成文件记录，上传人取当前用户，上传时间取系统时间并精确到秒。
2. 上传文件名与现有文件重名时，提示用户确认是否继续上传；确认后作为新文件记录保留，不直接覆盖原文件。
3. 点击“查看”打开文件预览；不支持在线预览时提供下载。
4. 点击“删除”弹出二次确认，确认后删除该文件；取消时不执行删除。
5. 点击“导出”，导出当前子项目全部外部机构归档文件；无文件时不可执行导出。
6. 上传、查看、删除和导出操作均受当前子项目权限控制；上传、删除和导出必须写入归档操作记录。

##### （4）归档状态变更

1. 点击归档结果区域的“变更”，打开归档状态弹窗。
2. 可选状态为未归档、归档中、归档完成；当前状态在弹窗中标识，不可重复选择当前状态。
3. 点击“保存”后更新当前子项目归档状态，并在归档操作记录中记录原状态、新状态、操作人和操作时间。
4. 点击“取消”或关闭弹窗，不保存状态变更。
5. 归档状态仅由用户通过“变更”操作手动修改，与归档文件数量及文件的一键归档、上传、删除、移动、替换、导出操作无关。
6. 修改归档状态不自动新增、删除、移动或修改任何归档文件。
