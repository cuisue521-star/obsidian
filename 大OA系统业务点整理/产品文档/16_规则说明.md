# 16_规则说明

## 编号规则

### 项目编号规则

| 规则 | 说明 |
|------|------|
| 格式 | **主体编码 + XM + 日期(YYMMDD) + 四位递增编号** |
| 示例 | **ZNLJXM2604010001** |
| 备注 | 各主体独立计数 |

### 子项目编号规则

| 规则 | 说明 |
|------|------|
| 格式 | **项目编号 - 顺序号** |
| 示例 | **ZNLJXM2604010001-1**（项目的第一个子项目），-2 类推 |

---

### 合同编号规则

| 规则 | 说明 |
|------|------|
| 主合同格式 | **资产编号 + -合同顺序编号** |
| 主合同示例 | **ZNLJZC2604010001-1**、**ZNLJZC2604010001-2** |
| 生成规则 | 主合同必须生成；一转、二转合同按生成顺序统一递增合同顺序编号 |
| 补充协议格式 | **原合同编号 + BC + 顺序号** |
| 补充协议示例 | **ZNLJZC2604010001-1-BC1** |
| 解约合同格式 | **原合同编号 + JY + 顺序号** |
| 解约合同示例 | **ZNLJZC2604010001-1-JY1**、**ZNLJZC2604010001-1-BC1-JY1** |
| 删除及解约后再生成 | 根据同一模板重新生成合同时，**沿用原合同编号** |
| 再次解约格式 | **原合同编号 + 解约次数 + JY + 顺序号** |
| 再次解约示例 | **ZNLJZC2604010001-1-2JY1** |
