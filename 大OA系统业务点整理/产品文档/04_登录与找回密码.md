# 登录与找回密码

## 页面 1：登录页 (Login Page)

### 1. 页面逻辑与交互 (UI Interactions)

- **默认状态：** 焦点默认置于“手机号”输入框。

- **密码明暗文切换：** 点击密码框右侧“眼睛”图标，切换显示明文/掩码（默认为掩码）。

- **忘记密码：** 点击跳转至 `找回密码 - 身份验证` 页面。

- **登录触发：**

  - 点击“登录”按钮或在密码框按 `Enter` 键触发。

  - **后端验证逻辑：**

    1. 校验账号状态（是否平台级封禁/注销）。

    2. 校验密码正确性。

    3. **成功后路由逻辑：**

       - 若用户关联企业数量 = 0：留在当前页，提示 toast 错误“当前账号无可登录企业” 。

         若用户关联企业数量 = 1：**跳过**选择企业页，自动进入工作台 。

         若用户关联企业数量 > 1：跳转至 `企业选择页` 。

### 2. 字段数据字典 (Data Constraints)

| **字段**   | **约束条件**                | **校验提示**                                         |
| ---------- | --------------------------- | ---------------------------------------------------- |
| **手机号** | 必填，11位数字，必须以1开头 | “请输入正确的手机号”                                 |
| **密码**   | 必填，8-20位字符            | “请输入正确的密码，包括英文大小写和数字中的至少三种” |

### 3. 异常与边界场景 (Edge Cases)

- **账号不存在：** 提交后提示“账号不存在” 。
- **密码错误封锁：**
  - 单次错误提示“密码错误”。
  - 连续错误 **5次**：触发锁定流程（前端需弹窗提示“密码输入错误次数过多，请稍后再试”。）
- **平台级停用：** 若账号被 停用，提示“账号已被停用，请联系管理员”，禁止进入任何页面 。

## 页面 2：找回密码 - 步骤1 身份验证 (Identity Verification)



### 1. 页面逻辑与交互 (UI Interactions)

- **返回登录：** 点击顶部“返回登录”或左上角箭头，返回登录页。

- **获取验证码：**

  - 点击“获取验证码”按钮。

  - **后端逻辑：** 检查手机号是否存在 。若存在，发送短信；若不存在，接口直接报错。提示：手机号不存在

  - **前端交互：** 按钮变为“60s后重新获取”并置灰倒计时 。

    

- **下一步：**

  - 点击“下一步”触发验证码校验接口。
  - 验证通过后，跳转至 `找回密码 - 步骤2 设置新密码`。

### 2. 字段数据字典 (Data Constraints)

| **字段**   | **约束条件**            | **校验提示**         |
| ---------- | ----------------------- | -------------------- |
| **手机号** | 必填，11位数字，以1开头 | “请输入正确的手机号” |
| **验证码** | 必填，6位纯数字         | “验证码错误”         |

### 3. 异常与边界场景 (Edge Cases)

- **手机号停用：** 点击获取验证码时，若后端返回停用，前端提示 toast “您的账号已被停用” 。

- **验证码频控限制：**

  - **60秒内重复点击：** 按钮保持置灰倒计时。

    

- **验证码过期/错误：**

  - 输入已过期的验证码（>10分钟）：提示“验证码已过期，请重新获取” 。

    输入错误验证码：提示“验证码错误”。

  - **防爆破：** 连续验证失败5次，冻结该功能30分钟。

## 页面 3：找回密码 - 步骤2 设置新密码 (Reset Password)



### 1. 页面逻辑与交互 (UI Interactions)

- **信息回显：** 顶部需脱敏显示当前正在操作的账号（如 `155****5555`）。
- **上一步：** 点击返回步骤1（注意：返回后通常需要重新验证或保留会话状态，建议保留验证通过的 Token）。
- **确认重置：**
  - 点击触发重置接口。
  - 成功后跳转至 `找回密码 - 完成页`。

### 2. 字段数据字典 (Data Constraints)

| **字段**       | **约束条件**                                 | **校验提示**                          |
| -------------- | -------------------------------------------- | ------------------------------------- |
| **新密码**     | 必填，8-20位，需包含大小写字母/数字中至少3种 | “密码复杂度不足” / “请输入8-20位字符” |
| **确认新密码** | 必填，必须与新密码完全一致                   | “两次输入的密码不一致”                |

### 3. 异常与边界场景 (Edge Cases)

- **与旧密码相同：** 若后端检测到新密码与旧密码（历史1次）相同，返回错误提示“新密码不得与近期密码相同” 。

  **会话超时：** 若用户在该页面停留超过限制时间（如 Token 失效），点击确认时提示“操作超时，请重新验证”，并跳转回步骤1。

## 页面 4：找回密码 - 完成页 (Success)



### 1. 页面逻辑与交互 (UI Interactions)

- **返回登录页面：** 点击按钮直接跳转回 `登录页`。
- **自动跳转：** 增加倒计时（ "5s 后自动返回登录页"）。

## 页面 5：选择企业页 (Tenant Selection)



### 1. 页面逻辑与交互 (UI Interactions)

- **进入前置条件：** 用户已成功通过登录验证，且该账号关联了 **≥ 2家** 企业 。

- **列表渲染：**

  - 展示后端返回的企业列表。
  - **显示内容：** 企业名称、加入时间（第一次添加时间，若该企业删除该用户又重新添加，记录的是第一次添加时间）。

- **选择动作：**

  - 点击列表项，卡片高亮（选中态）。
  - 点击“进入选中企业”按钮，调用 Token 切换接口（换取该 Tenant 下的 Access Token）。
  - 成功后跳转至 `工作台首页`。

- **记忆逻辑：** 成功进入后，系统需记录该企业 ID 为 `last_login_tenant` 。

  

### 2. 字段数据字典 (Data Constraints)

| **字段**     | **说明**                                             |
| ------------ | ---------------------------------------------------- |
| **企业列表** | 仅显示状态正常（未过期/未冻结）且用户有权限的企业 。 |

### 3. 异常与边界场景 (Edge Cases)

- **权限突然移除：** 用户停留在该页面时，管理员在后台将其移除了某企业。用户点击该企业卡片 -> 进入 -> 接口报错（403） -> 前端自动刷新列表，移除该选项。

- **所有企业均失效：** 若刷新后发现列表为空，提示“当前账号无可登录企业”，并强制退出登录 。

- **Token 过期：** 停留过久导致 Login Token 失效，点击进入时提示“登录已过期”，跳转回登录页。
