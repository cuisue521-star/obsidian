# 08\_流程发起、查看

## 流程管理

在「流程管理」一级菜单下，可查看流程信息。项目、征信等业务数据按主体隔离；待处理、已提交、待推送、消息等处理类数据可按企业分组跨主体聚合查看，避免同一批运营人员遗漏事项。包含以下子列表：

- 全部
- 待处理
- 抄送我的
- 已处理
- 已提交
- 草稿

### 通用功能

- **发起入口**：页面顶部固定显示【发起申请】按钮
- **分页规则**：所有列表均支持分页，默认每页展示 10 条

***

### 1. 全部

#### 筛选项

1. 项目名称：模糊查询
2. 子项目名称：模糊查询
3. 流程编号：精准查询
4. 发起人：模糊搜索（范围为列表内的发起人）
5. 流程类型：下拉选择，多选
6. 审批状态：下拉选择，多选
7. 全局检索：支持页面级文本搜索（类比 `Ctrl+F`，可检索列表及页面内所有信息）

#### 列表

1. **排序规则**：默认按「发起时间」倒序排列
2. **展示字段**：展示所有的合集，根据状态判断
3. **操作**：展示所有的合集，根据状态判断
4. **去重规则**：由于一个流程可能存在多个状态，例如待处理、已处理、抄送我等，故需要进行去重。优先级：待处理＞抄送我＞已处理＞已提交。注意，草稿不在全部里展示。

***

### 2. 待处理

#### 筛选项

同全部

#### 列表

1. **排序规则**：默认按「发起时间」倒序排列
2. **展示字段**：发起人、发起时间（精确到秒）、流程名称、流程编号、流程状态、流程特有字段（按流程类型动态展示 3 个字段）、流程审批状态、总耗时（天、时、分、秒）、当前等待（天、时、分、秒）
3. **操作**：处理：进入待办处理页面。查看：进入流程详情页。

***

### 3. 抄送我的

#### 筛选项

基于「全部」列表的筛选项，新增：

1. 抄送人：模糊搜索（范围为列表内的抄送人）
2. 阅读状态：下拉选择（已读 / 未读）

#### 列表

基于「全部」列表的字段，调整如下：

1. 将「发起时间」替换为「抄送时间」
2. 新增「抄送人」字段
3. 新增「阅读状态」状态。未读、已读。每次抄送更新阅读状态。点击视为已读。
4. 无需展示总耗时及当前等待
5. **去重规则**：同一流程多次抄送同一用户时，仅展示 1 条记录，且更新为最新的抄送人和抄送时间
6. **快捷操作**：列表顶部增加【全部已读】按钮，点击后一键标记所有记录为已读，无二次弹窗
7. **操作**：查看。点击视为已读。
8. **排序**：默认按「抄送时间」倒序排列

***

### 4. 已处理

#### 筛选项

同待处理

#### 列表

同待处理差异：

1. 不展示当前等待时间和总耗时
2. 增加处理时间，精确到秒
3. 按照处理时间倒序
4. 去重，仅展示 1 条记录，且更新为最新的处理时间

***

### 5. 已提交

#### 筛选项

同待处理差异：不展示发起人筛选项

#### 列表

同待处理差异：

1. 增加字段：当前处理人。取审批人或办结人。仅未结束的流程展示，审批通过、已办结、已作废、已撤销、已拒绝、已驳回的流程不展示。
2. **操作**：

- 撤销：审批中，未审批完成，未进入办结的流程可撤销
- 催办：未结束的流程（见上方）支持催办
- 处理：已驳回的流程
- 查看：全部展示。进入流程详情页。

1. **工作台差异**：

- 此处展示**所有已提交的流程（含已结束）**
- 工作台仅展示「已提交但未结束」的流程

***

### 6. 草稿

仅展示核心字段：流程名称、保存时间

1. **删除**：点击后弹出二次确认框（确认删除该流程？【取消】/【确认删除】）
2. **编辑**：点击进入编辑页；若用户所属部门已变更导致流程无法匹配，弹窗提示：「您的部门已变更，请删除后重新发起」，关闭弹窗后无法进入编辑页。注意！不是所有的用户变更部门都不可以编辑。

## 发起

### 步骤

1. 选择部门（若仅存在一个部门，可跳过此步骤）
2. 选择流程
3. 录入参数
4. 保存 / 发起

### 征信企业报送——企业基本信息

在「选择流程 > 征信报送」中点击【企业基本信息】，打开报送场景选择弹窗。

| 字段    | 类型   | 必填   | 功能说明                                                |
| ----- | ---- | ---- | --------------------------------------------------- |
| 项目状态  | 单选   | 是    | 默认选择「已完成项目立项」，用于限定可选项目范围                            |
| 项目名称  | 下拉选择 | 是    | 仅展示当前用户有权限且已完成立项的项目                                 |
| 子项目名称 | 下拉选择 | 是    | 根据项目名称联动，仅展示所选项目下的子项目（权限内）                          |
| 报送类型  | 单选   | 是    | 支持「正常类数据报送」「变更类数据报送」（第一批次-2026年11月前不做变更类）           |
| 报送时点  | 下拉选择 | 是    | 支持「新增客户资料 / 首次上报」「更新客户资料」                           |
| 客户名称  | 下拉选择 | 条件必填 | 选择「更新客户资料」时展示，范围是合作中心报送过企业征信的（注意数据迁移后重点测试）；首次上报时不展示 |

**场景规则**：

1. **新增客户资料 / 首次上报**：选择项目、子项目、报送类型后确认，进入企业基本信息填报页，用于首次报送企业数据。
2. **更新客户资料**：除选择项目、子项目和报送类型外，必须选择客户名称；确认后进入填报页并反显该企业已有信息，用于更新报送。
3. 点击【确认】前校验全部必填项；校验通过后进入对应流程填报页。点击【取消】或关闭弹窗不保留本次选择。

### 征信企业报送——授信协议信息

在「选择流程 > 征信报送」中点击【授信协议信息】，打开授信报送场景选择弹窗。

| 字段    | 类型   | 必填   | 功能说明                                                                  |
| ----- | ---- | ---- | --------------------------------------------------------------------- |
| 项目状态  | 单选   | 是    | 默认选择「已完成项目立项」，用于限定可选项目范围                                              |
| 项目名称  | 下拉选择 | 是    | 仅展示当前用户有权限且已完成立项的项目                                                   |
| 子项目名称 | 下拉选择 | 是    | 根据项目名称联动，仅展示所选项目下用户有权限的子项目                                            |
| 报送类型  | 单选   | 是    | 支持「正常类数据报送」「变更类数据报送」（第一批次不做变更类）                                       |
| 报送时点  | 下拉选择 | 是    | 支持「授信开始」「额度调整」「授信到期/失效」                                               |
| 授信信息  | 下拉选择 | 条件必填 | 选择「额度调整」或「授信到期/失效」时展示；列出所选子项目内全部通过的历史授信报送流程，选项展示受信人、授信额度、流程编号。发起时间倒序。 |

**场景规则**：

1. **授信开始**：选择项目、子项目和报送类型后确认，进入授信信息填报页，用于建立该子项目的首次或新增授信报送。
2. **额度调整**：必须选择该子项目内已有的授信信息；确认后反显所选授信数据，用于更新授信额度等信息。
3. **授信到期/失效**：必须选择该子项目内已有的授信信息；确认后反显所选授信数据，用于报送该笔授信到期或失效。
4. 授信按子项目独立管理。每个子项目的授信分别报送；同一子项目发生多次放款时，授信报送及后续更新均归属于该子项目，不得选择其他子项目的授信信息。
5. 切换项目或子项目时，清空已选授信信息，并重新加载所选子项目内的授信报送流程。
6. 点击【确认】前校验全部必填项；校验通过后进入对应流程填报页。点击【取消】或关闭弹窗不保留本次选择。

### 征信信息报送——抵质押信息

在「选择流程 > 征信报送」中点击【抵质押信息】，打开抵质押报送场景选择弹窗。

| 字段    | 类型   | 必填   | 功能说明                                                                                |
| ----- | ---- | ---- | ----------------------------------------------------------------------------------- |
| 项目状态  | 单选   | 是    | 默认选择「已完成项目立项」，用于限定可选项目范围                                                            |
| 项目名称  | 下拉选择 | 是    | 仅展示当前用户有权限且已完成立项的项目                                                                 |
| 子项目名称 | 下拉选择 | 是    | 根据项目名称联动，仅展示所选项目下用户有权限的子项目                                                          |
| 报送类型  | 单选   | 是    | 支持「正常类数据报送」「变更类数据报送」（第一批次不做变更类）                                                     |
| 报送时点  | 下拉选择 | 是    | 支持「合同生效」「合同到期/失效」「抵（质）押物变更」                                                         |
| 债务人名称 | 下拉选择 | 条件必填 | 选择「合同到期/失效」或「抵（质）押物变更」时展示；列出所选子项目下抵质押报送涉及的债务人                                       |
| 抵质押信息 | 下拉选择 | 条件必填 | 选择「合同到期/失效」或「抵（质）押物变更」时展示；根据债务人联动，列出所选子项目下该债务人的全部通过的历史抵质押流程，选项展示担保金额、流程编号，按发起时间倒序排列 |

**场景规则**：

1. **合同生效**：选择项目、子项目和报送类型后确认，进入抵质押信息填报页，用于新增该子项目的抵质押报送。
2. **合同到期/失效**：必须选择债务人及该子项目内已有的抵质押信息；确认后反显所选流程数据，用于报送合同到期或失效。
3. **抵（质）押物变更**：必须选择债务人及该子项目内已有的抵质押信息；确认后反显所选流程数据，用于更新抵押物或质押物信息。
4. 抵质押按子项目独立管理。抵质押信息仅可选择当前子项目下的历史抵质押流程，不得跨子项目选择。
5. 切换项目或子项目时，清空债务人名称和抵质押信息；切换债务人时，清空抵质押信息并重新加载对应流程。
6. 点击【确认】前校验全部必填项；校验通过后进入对应流程填报页。点击【取消】或关闭弹窗不保留本次选择。

抵质押三个时点规则区分说明：

1. 合同生效：正常录入；
2. 合同到期/失效：带出关联的审批单，可修改。其余除信息报告日期，均不可修改。
3. 抵（质）押物变更：带出关联的审批单和资产，除抵质押合同标识码其他均可修改。

#### 字段联动规则

1. 切换项目名称时，清空子项目名称、企业名称、资金运用流程和借贷账户信息，并重新加载该项目下可选子项目。
2. 切换子项目名称时，清空企业名称、资金运用流程和借贷账户信息，并重新执行子项目征信报送标识校验；同时根据当前报送时点重新查询可选资金运用流程或借贷账户信息。
3. 切换报送时点时，清空原报送时点下已选择的企业名称、资金运用流程或借贷账户信息，避免沿用不适用于新时点的数据。
4. 报送时点为“账户开立”时，展示企业名称和资金运用流程，隐藏借贷账户信息。企业名称与所选项目、子项目联动；企业不属于所选项目时，提示“该企业未体现在子项目内，请确认企业信息是否准确”，仅提醒、不阻断。判断范围包括子项目核企、已入池资产的转让方、债务人、原始债权人、原始债务人。
5. 账户开立时，资金运用流程仅展示所选子项目下当前用户有权限查看且已审批通过的流程，支持多选；确认后将全部已选流程带入 D1 表单的“关联资金运用流程”，按发起时间倒序展示。
6. 报送时点不是“账户开立”时，隐藏企业名称和资金运用流程，展示借贷账户信息。借贷账户信息**仅支持单选**。
7. 借贷账户信息仅展示所选项目、子项目下已完成账户开立报送且当前用户有权限查看的 D1 借贷账户；已作废、已撤销、已拒绝的账户开立流程不进入选项。注意这里选择的是账户而不是流程。（背景说明，当前一个子项目下多次录入，且涉及多个账户，选择流程的交互不方便选择）
8. 借贷账户选项固定展示“借款人名称：XXX　借款金额：XXX元　账户标识码：XXXX”，按账户开立流程完成时间倒序排列；同一借贷账户仅展示一次。
9. 选择借贷账户信息后，点击【确认】进入 D1 表单，系统反显该借贷账户最近一次有效报送的数据，并沿用其借款人、授信协议标识码、借贷业务标识码及已关联的业务信息；具体可编辑字段按所选报送时点规则控制。具体的金额计算取最新的计算金额。

#### 提示与确认交互

1. 阻断校验不通过时，在对应字段下方展示错误提示，并禁止点击【确认】进入 D1 表单。
2. 企业不在所选项目内属于账户开立场景的提醒类校验，不直接阻断；点击【确认】时弹出二次确认，用户选择继续后方可进入 D1 表单。
3. 非账户开立场景下，借贷账户信息不存在可选项时，下拉框展示“暂无可选借贷账户信息”，【确认】按钮不可用。
4. 用户选择借贷账户时，系统校验该账户是否已存在未结束的 D1 报送流程。若存在，字段下方展示提示“该借贷账户存在未结束的报送流程，请在原流程结束后再发起”，不得进入新的 D1 表单。
5. “未结束的 D1 报送流程”包括草稿、待提交、审批中、已驳回待重新提交及其他尚未进入终态的流程；审批通过、已办结、已作废、已撤销、已拒绝的流程视为已结束。
6. 同一借贷账户任一时刻最多允许存在一条未结束的 D1 报送流程，不区分报送时点和发起人。点击【确认】时必须再次校验，避免多人同时操作产生多条进行中流程。
7. 用户选择借贷账户后，点击【确认】时系统重新校验账户有效性、项目归属、账户状态及进行中流程唯一性；校验失败时保留弹窗内其他已选值，并清空不可继续使用的借贷账户信息。
8. 同时存在多项阻断校验时，页面逐项展示全部错误信息，用户修正后重新校验。
9. 点击【取消】或关闭弹窗，不保留本次选择。

#### 字段联动规则

1. 切换项目名称时，清空子项目名称、企业名称和借贷账户信息，并重新加载该项目下可选子项目。

8. 借贷账户选项按账户开立流程完成时间倒序排列；同一账户标识码仅展示一次，展示该账户最新有效信息。

#### 提示与确认交互

1. 阻断校验不通过时，在对应字段下方展示错误提示，并禁止点击【确认】进入 C1 表单。
2. 企业不在所选项目内属于账户开立场景的提醒类校验，点击【确认】时弹出二次确认；用户确认继续后进入 C1 表单。
3. 非账户开立场景下无可选借贷账户时，下拉框展示“暂无可选借贷账户信息”，【确认】按钮不可用。
4. 用户选择借贷账户时，系统校验该账户是否存在未结束的 C1 报送流程；存在时不得进入新的 C1 表单。
5. 同一借贷账户任一时刻最多允许存在一条未结束的 C1 报送流程，不区分报送时点和发起人。点击【确认】时必须再次校验。
6. “账户关闭”报送完成后，该账户仍可在下拉列表中展示，但不得继续发起新的 基于该账户的C1 报送流程。
7. 点击【取消】或关闭弹窗，不保留本次选择。

#### 报送时点规则

1. 账户开立时必须新建 C1 借贷账户，不允许在弹窗内选择已有账户。
2. 所有非账户开立时点必须基于一个已有且有效的 C1 借贷账户发起，不允许新建借贷账户。

#### 取消

- 若已录入信息，点击【取消】弹窗提示：取消后您录入的信息将会丢失，确认退出吗？取消/确认退出

- 保存当前已填写的表单信息、审批流程配置等全部内容

- 提交成功后，流程进入审批环节，状态更新为「审批中」
- 提交后无法再编辑当前流程内容（若需修改需走撤回或作废流程，以实际系统规则为准）

## 审批结果选项

### 1. 通过

- **触发条件**：选择「通过」选项

  2. 输入审批意见

- **页面反馈**：
  - 审批意见输入框激活
  - 提交成功后流程进入下一环节

### 2. 驳回

- **触发条件**：选择「驳回」选项
- **执行流程**：
  1. 选择「驳回」单选按钮
  2. 在「请选择发起人再次提交」下拉框中选择直送驳回审批人或重新提交流程。
  3. 输入审批意见
  4. 点击「提交」按钮
- **页面反馈**：
  - 显示「请选择发起人再次提交时」下拉框
  - 提交成功后流程返回给指定发起人
- **说明**
  - 直送驳回审批人：驳回后发起人重新发起，跳过前述审批人，直到驳回人。
  - 重新提交流程： 驳回后发起人重新发起，需要走全部流程。

### 3. 转交

- **触发条件**：选择「转交」选项
- **执行流程**：
  1. 选择「转交」单选按钮
  2. 输入审批意见
  3. 点击「提交」按钮
- **页面反馈**：
  - 转交意见输入框激活
  - 提交成功后流程转交给其他审批人

### 4. 加签

- **触发条件**：选择「加签」选项
- **执行流程**：
  1. 选择「加签」单选按钮
  2. 点击「请选择加签审批人」下拉框
  3. 在弹出的加签审批人选择弹窗中：
     - 点击「+」按钮添加加签审批人
     - 选择加签方式：
       - 「在我之前」：加签后，流程先经过加签审批人依次审批，再由我审批
       - 「在我之后」：在我之后加签，即表示同意该申请并请加签审批人员依次审批
     - 点击「发送」或「确认」按钮
  4. 输入加签意见
  5. 点击「提交」按钮
- **页面反馈**：
  - 显示「请选择加签审批人」下拉框
  - 弹出加签审批人选择弹窗
  - 可添加多个加签审批人
  - 提交成功后流程进入加签审批环节

## 快捷工具

### 合同比对

#### 1. 页面信息架构

**页面分为 2 个区域：**

1. **左侧合同附件区域**
   - 标题栏：合同附件 + 已选数量/总数 + 全选按钮
   - 文件列表：复选框、文件名称、上传时间、文件大小
   - 文件项支持单选/多选
2. **右侧模板上传与比对区域**
   - 页面标题：流程管理 / 合同比对
   - 副标题：上传合同模板并选择附件进行比对，检测模板内容是否被篡改
   - 模板上传区：拖拽上传或点击上传，支持文件大小不超过500MB
   - 已上传模板列表：文件名、上传时间
   - 比对准备区：检查项列表（1.请上传模板、2.请选择需要比对附件）
   - 开始比对按钮
   - 对比报告区：总对比数、发现篡改、差异位置统计、文件对比详情

#### 2. 功能逻辑详情

##### 2.1 合同附件选择

**触发条件**：进入合同比对页面时自动加载

**执行流程**：

1. 加载当前流程的所有合同附件
2. 显示文件列表（文件名、上传时间、文件大小）
3. 用户可通过复选框选择需要比对的附件
4. 支持全选/取消全选

**页面反馈**：

- 已选数量实时更新（如：已选3/20）
- 选中项高亮显示
- 至少选择1个附件后才能开始比对

##### 2.2 模板上传

**触发条件**：点击上传区域或拖拽文件到上传区

**执行流程**：

1. 用户选择或拖拽合同模板文件（PDF和word格式）
2. 显示上传进度（0%-100%）
3. 上传完成后显示文件信息（文件名、上传时间）
4. 支持上传多个模板文件

**页面反馈**：

- 上传进度条实时显示
- 上传成功后文件添加到已上传列表
- 文件大小不超过500MB

##### 2.3 开始比对

**触发条件**：点击「开始比对」按钮

**执行流程**：

1. 检查比对准备条件：
   - 已上传模板（检查项1）
   - 已选择需要比对的附件（检查项2）
2. 条件满足后，开始执行比对
3. 显示比对中状态
4. 比对完成后展示对比报告

**页面反馈**：

- 按钮显示比对中状态（loading）
- 检查项显示完成状态（绿色勾选）
- 比对完成后显示对比报告

##### 2.4 对比报告展示

**触发条件**：比对完成后自动展示

**执行流程**：

1. 显示统计信息：
   - 总对比数（如：3）
   - 发现篡改（如：1）
   - 差异位置（如：3）
2. 显示文件对比列表：
   - 正常文件：绿色标识
   - 发现篡改文件：橙色标识 + 差异数量
3. 展开篡改文件详情：
   - 显示差异位置（第2页、第8页、第16页）
   - 模板内容 vs 差异内容对比

**页面反馈**：

- 统计卡片展示关键数据
- 文件列表可展开/收起
- 差异内容高亮显示（红色标注差异部分）

#### 3. 交互细节说明

##### 3.1 文件选择交互

- **单选**：点击复选框选择单个文件
- **全选**：点击顶部「全选」按钮选择所有文件
- **已选计数**：实时显示已选文件数量（如：已选3/20）

##### 3.2 模板上传交互

- **拖拽上传**：将文件拖拽到上传区域
- **点击上传**：点击上传区域打开文件选择器
- **上传限制**：文件大小不超过500MB
- **多文件支持**：可上传多个模板文件

##### 3.3 比对准备检查

- **检查项1**：请上传模板（未上传时灰色，上传后绿色勾选）
- **检查项2**：请选择需要比对附件（未选择时灰色，选择后绿色勾选）
- **开始比对按钮**：条件不满足时禁用，条件满足后启用

##### 3.4 对比报告交互

- **统计卡片**：点击可筛选对应状态的文件
- **文件项展开**：点击展开按钮查看差异详情
- **差异定位**：点击差异位置快速定位到对应页面
