适用端：运营端。权限，按钮权限，非项目权限。

运营端可跨主体查看当前主体的资金总览信息。企业端工作台不展示应收、应付等资金统计，见 `20_企业端_登录与认证.md`。

# 09\_01\_工作台\_资金总览

## 一、页面要素说明

| 模块     | 说明                            |
| ------ | ----------------------------- |
| 资金统计卡片 | 展示今日应收、今日应付、本月回款、本月放款四类资金统计数据 |
| 今日应收款项 | 展示今日应收款项列表及导出入口               |
| 今日应付款项 | 展示今日应付款项列表及导出入口               |

## 二、功能逻辑详情

### （一）资金统计卡片

#### 字段清单

| 字段名  | 说明                     |
| ---- | ---------------------- |
| 今日应收 | 展示当前主体今日应收总金额，并展示应收笔数。 |
| 今日应付 | 展示当前主体今日应付总金额，并展示应付笔数  |
| 本月回款 | 展示当前主体本月回款总金额          |
| 本月放款 | 展示当前主体本月放款总金额          |

#### 取值规则

1. **今日应收**：从还款计划取数，统计当前主体今日应收款项的金额合计；笔数取今日应收款项数量。若无还款计划，展示“-”；若有还款计划但今日无应收，展示0。
2. **今日应付**：从付款计划取数，统计当前主体今日应付款项的金额合计；笔数取今日应付款项数量。若无付款计划，展示“-”；若有付款计划但今日无应付，展示0。
3. **本月回款**：从实际还款信息取数，以实际还款时间为准，统计当前主体本月实际还款金额合计。
4. **本月放款**：从资金运用流程取数，取流程中的本次支付金额和支付日期，统计当前主体本月放款金额合计。
5. 金额单位按页面展示为“万”，两位小数，四舍五入。

### （二）今日应收款项

#### 列表字段

| 字段名   | 说明                          |
| ----- | --------------------------- |
| 子项目名称 | 展示应收款项所属子项目名称               |
| 实际还款方 | 展示该笔应收款项对应的还款人 ，取还款计划的实际还款人 |
| 金额（元） | 展示该笔应收款项金额                  |
| 费用类型  | 展示该笔应收款项的费用类型               |

#### 列表规则

1. **仅展示今日应收款项数据**。还款计划取值
2. 标题处展示当前列表总笔数，格式为“今日应收款项（共X笔）”。
3. 每一个细项是一行。
4. 金额以元为单位展示。
5. 无需分页，按子项目分组，子项目内按同一个还款计划分组。

#### 导出

**触发条件**：点击今日应收款项区域的“导出”按钮。

**执行流程**：

1. 系统获取当前今日应收款项列表数据。
2. 导出列表字段数据。

**结果说明**：生成今日应收款项导出文件。命名，格式为“今日应收款项\_YYYYMMDD.xlsx”，其中YYYYMMDD为当前日期。

### （三）今日应付款项

#### 列表字段

| 字段名     | 说明                      |
| ------- | ----------------------- |
| 子项目名称   | 展示应付款项所属子项目名称           |
| 收款企业    | 展示该笔应付款项对应的收款企业         |
| 应付金额（元） | 展示该笔应付款项金额              |
| 备注      | 展示该笔应付款项备注信息；无备注时显示“--” |

#### 列表规则

1. **仅展示今日应付款项数据**。付款计划取值
2. 标题处展示当前列表总笔数，格式为“今日应付款项（共X笔）”。
3. 应付金额以元为单位展示。
4. 无需分页，按子项目分组，子项目内按付款计划分组

#### 导出

**触发条件**：点击今日应付款项区域的“导出”按钮。命名，格式为“今日应付款项\_YYYYMMDD.xlsx”，其中YYYYMMDD为当前日期。

**执行流程**：

1. 系统获取当前今日应付款项列表数据。
2. 导出列表字段数据。

**结果说明**：生成今日应付款项导出文件。

### （四）资金日历

#### 页面要素说明

| 模块    | 说明                  |
| ----- | ------------------- |
| 月份切换  | 展示当前月份，支持切换上一月、下一月  |
| 今日按钮  | 点击后切换回当前日期所在月份，定位今天 |
| 日历日期格 | 按日期展示当日应收和应付金额      |

#### 日历展示规则

1. **日历按月展示当前月份日期**。
2. 每个日期格展示该日期对应的应收金额和应付金额。
3. 应收金额取还款计划中对应日期的应收金额。
4. 应付金额取付款计划中对应日期的应付金额。
5. 日期无应收、应付数据时，不展示金额。
6. 点击上一月或下一月后，切换日历月份并刷新当月应收、应付数据。
7. 点击“今日”后，日历回到当前日期所在月份。

### （五）导出还款计划

**触发条件**：点击“导出还款计划”。

**执行流程**：

1. 系统打开“选择导出项目”弹窗。
2. 用户筛选并勾选需要导出的项目。
3. 点击“确定导出”后，系统导出所选项目的还款计划文件。

**结果说明**：生成还款计划导出文件。

**文件命名**：还款计划\_YYYYMMDD.xlsx。

### （六）导出付款计划

**触发条件**：点击“导出付款计划”。

**执行流程**：

1. 系统打开“选择导出项目”弹窗。
2. 用户筛选并勾选需要导出的项目。
3. 点击“确定导出”后，系统导出所选项目的付款计划文件。

**结果说明**：生成付款计划导出文件。

**文件命名**：付款计划\_YYYYMMDD.xlsx。

### （七）选择导出项目弹窗（还款和付款计划同样）

#### 页面要素说明

| 模块   | 说明                         |
| ---- | -------------------------- |
| 弹窗标题 | 展示“选择导出”                   |
| 导出维度 | 支持“按项目维度导出”和“按时间维度导出”切换    |
| 筛选区域 | 支持按项目名称、子项目名称、业务类型、子项目状态筛选 |
| 项目列表 | 展示可导出的项目及子项目信息             |
| 已选数量 | 展示当前已勾选项目数量                |
| 分页   | 展示总条数、每页条数和分页页码            |
| 操作按钮 | 包含“取消”和“确定导出”              |

#### 筛选项

| 筛选项名称 | 匹配规则    |
| ----- | ------- |
| 项目名称  | 模糊匹配    |
| 子项目名称 | 模糊匹配    |
| 业务类型  | 下拉，精确匹配 |
| 子项目状态 | 下拉，精确匹配 |

#### 表格字段

| 字段名     | 说明                               |
| ------- | -------------------------------- |
| 选择      | 勾选需要导出的项目                        |
| 项目名称    | 展示项目名称。项目按创建时间倒序                 |
| 子项目名称   | 展示子项目名称。列表按照项目分组，项目内，子项目按创建时间倒序。 |
| 业务类型    | 展示子项目业务类型                        |
| 项目状态    | 展示项目当前状态                         |
| 融资金额（元） | 展示子项目融资金额，若空展示“—”                |

#### 功能规则

1. **查询**：点击“查询”后，按当前筛选条件刷新项目列表。
2. **重置**：点击“重置”后，清空筛选条件并恢复默认列表。
3. **当前页全选**：勾选“当前页全选”后，选中当前页全部项目。
4. **已选数量**：根据当前勾选结果实时展示，格式为“已选X项”。
5. **确定导出**：未选择项目时不可点击；选择项目后，按钮展示“确定导出（X）”。
6. **取消**：点击“取消”或关闭弹窗，关闭弹窗且不导出。
7. **导出文件命名**：导出还款计划时，文件名为“还款计划\_YYYYMMDD.xlsx”；导出付款计划时，文件名为“付款计划\_YYYYMMDD.xlsx”。YYYYMMDD取导出当天日期。

#### 按项目维度导出

**触发条件**：在“选择导出”弹窗中选择“按项目维度导出”。

**执行流程**：

1. 用户按项目名称、子项目名称、业务类型、子项目状态筛选项目。
2. 用户勾选需要导出的子项目。
3. 点击“确定导出”后，系统导出所选子项目的还款计划或付款计划。

**导出规则**：

1. **一个Excel文件内，一个子项目生成一个Sheet**。
2. 每个Sheet展示该子项目下对应的还款计划或付款计划数据。
3. 表格内容同还款计划或付款计划。

#### 按时间维度导出

**触发条件**：在“选择导出”弹窗中选择“按时间维度导出”。

##### 页面要素说明

| 模块   | 说明                                                                                                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 日期类型 | 支持选择约定还款日期、约定付款日期、放款日期、到期日期。约定还款日期取还款计划的，约定付款日期取付款计划的，放款日期取还款计划关联的资金运用流程的支付日期，到期日期取还款计划最晚约定还款日期。注意类型和还款计划和付款计划有关。还款计划：展示约定还款日期、放款日期、到期日期。付款计划：展示约定付款日期。 |
| 日期范围 | 选择导出的日期范围                                                                                                                                               |
| 快捷日期 | 支持本月、近三月、近半年、今年 。限制最大导出范围为12个月                                                                                                                          |
| 操作按钮 | 包含“取消”和“确定导出”                                                                                                                                           |

<br />

##### 执行流程

1. 用户选择日期类型。
2. 用户选择日期范围，或点击快捷日期快速生成日期范围。
3. 点击“确定导出”后，系统导出所选时间范围内命中的还款计划或付款计划。

##### 导出规则

1. **按照时间维度导出时，命中的所有还款计划或付款计划均导出到同一个Sheet页**。注意，这里是指的细项，例如一个还款计划有一行命中，仅导出该行。导出数据也会不同。
   1. 约定还款日期：取命中约定还款日期的所有行
   2. 约定付款日期：取命中约定付款日期的所有行
   3. 放款日期：取命中资金运用流程关联的所有还款计划
   4. 到期日期：取命中到期日期的整个还款计划，而不是仅导出到期日那一行。
2. 导出顺序：
   1. 若还款计划，按约定还款日期倒序。
   2. 若付款计划，按付款日期倒序。
   3. 同还款计划或付款计划同日期挨着。
3. **导出字段需在第一行增加“子项目名称”字段**，用于标识每条计划所属子项目。
4. 未选择日期类型或日期范围时，不执行导出。
